## 2. Decisions taken in the data

1. **`objectSelected` is on unless the route says no.** SPEC-2 1.1 makes every top level block of every slide kind an object, so `selection.object` defaults to true when the field is absent and the Arrange, Rotate and Group rows enable on any block selection before the route wires the field; the route sets `object: false` for a block nested inside another. `rotatable` and `canGroup` read the same field (4.1, last row).
2. **Show ruler has no check mark.** Google relabels the row (R01 View: "label flips to Hide ruler"). `MenuItem.plain` marks a toggle drawn as a plain row; `isChecked` returns undefined for it, so the Menu draws a `menuitem` and `resolveLabel` reads Hide ruler while `settings.showRuler` is on. Show guides keeps its check.
3. **A conditional divider.** The covering picture's appended rows (0.100) start with a divider that shows only with them, so `ContextEntry` allows `{ id: DIVIDER, when }` and `contextMenuItems` pushes the divider when the predicate holds. `contextMenuIds` gives the tests and the audit the ids without dividers.
4. **Delete guide carries no input.** The guide under the pointer is known only at click time, so `view.guides.delete` is `action('deck.guides')` and the shell's `menuActionPlan` fills `remove` (day two).
5. **The rotate aliases are separate bindings.** `shortcuts.test.ts` holds every bound chord to Google's rows, so Cmd+Option+Left and Right cannot join the Option+Left row's binding; they are alias bindings with `google: []` in `TURBOSLIDE_ONLY_KEYS`, and Google's rows carry the note the dialog prints (0.78). `ShortcutsDialog.tsx` reads `note` and `alias` on a later day.
6. **The misspelling rows are omitted.** Section 9 fixes the greyed list and does not name them; the page cannot drive the browser's spelling marks, so they leave the dialog rather than stay greyed.
7. **Change background is a leaf.** 0.74 retires the picture kinds' Replace image submenu; the row is `dialog('Background')` on every slide kind. `pictureTargetOf('slide.changeBackground', ...)` still names the slide until the Background dialog lands (day two) and its test reads the parent id.
8. **The fixture grows by the rows R05 attests.** The R01 test holds every non Turboslide, non context-only row to the fixture, so the dash, decoration, capitalization and paragraph spacing rows are in `google-menus.json` with their R05 sources; the decoration labels are the enum values in sentence case because Google prints no tooltip names for them (R05 A10).
9. **The legacy shape strip.** `SHAPE_KINDS` now lists every preset (B1's shapes table) and the Prototemplate strip and palette have words and glyphs for five, so they iterate `LEGACY_SHAPE_VARIANTS` until the shape picker draws the table from `shapes.ts` (deliverable 2).

## 7. Decisions taken on day two

1. **`DrawTool` is widened as the seams list says.** The route's `toEditorTool` (`apps/studio/src/routes/edit.$deckId.tsx`, the integrator's) is the one consumer and needs the new kinds (request 1 below, with the replacement). Until then the root `tsc -b` reports two errors on that function; `tsc -b packages/chrome` does not build the studio.
2. **A grammar slide's fields are objects to the shell.** `pseudoBlockOf` gives a Title slide's `heading`, `lead` and `mark`, a statement's `big` and a picture kind's `picture` and `plate` a synthetic block, so the menus, the tails and Format options treat them as SPEC-2 1.1 says before the first write converts the slide; a write on one goes through the store action, which converts or refuses with its own sentence.
3. **Order on a grammar slide plans `block.order`.** The round one `block.move` within a slot retires for the Arrange rows (SPEC-2 6.1 row 13, 1.6); the Order predicates read document order as the z the first pick gives the objects.
4. **Inserts never land in a slot.** `insertBlockPlan` writes `slot: 'main'` and a centred `pos` on every slide kind; the store action converts (1.6, 0.8). The round one refusal `needsBody` no longer fires from the Insert rows.
5. **The Background dialog's Choose without the handle is two writes.** `block.insert` lands the picture object on top of the stack (B1's `withCanvas` rule), so `block.order` with `move: 'back'` follows with the returned revision; `editor.insertBackgroundPicture` makes it one write once B4 and the integrator wire it.
6. **The measured box of a grammar block comes from the route.** `EditorShellInput.measuredBoxes` (sheet px, by block id) is how Size & rotation and Position show a grammar slide's block before its first edit (section 5 row 1); without it the fields are disabled with "Move or resize the object once to see its size here". The integrator passes the stage's boxes (request 2).
7. **Format options opens at a section through `openPanel(id, { section })`**; the section is scrolled into view and its head focused (`scrollIntoView` guarded for jsdom).
8. **The alt textarea has its own control id** (`formatOptions.altText.description`); the section head keeps `formatOptions.altText`, a round one clash the new test found.
9. **The lint findings test has a ceiling.** Seventeen round one rules cite `DECK-GRAMMAR.md` or say twin, native, run, source or measure in their proposals (the lint package, B1); the test pins them as a ceiling no round two rule may join and holds every other finding to the list (request 4).

## 8. Requests to the integrator (day two)

1. **`toEditorTool` in `apps/studio/src/routes/edit.$deckId.tsx` (root `tsc -b`: TS2366 at 2359, TS2678 at 2363).** The shell's `DrawTool` is now `{ kind: 'text' } | { kind: 'shape'; shape: string } | { kind: 'line'; line: 'line' | 'arrow' | 'rule' | 'elbow' | 'curved' | 'curve' | 'polyline' | 'scribble' } | { kind: 'table'; columns; rows } | { kind: 'chart'; chart } | { kind: 'wordArt'; text }`. Until B4's `EditorTool` carries the same kinds, a replacement that compiles and keeps the round one tools:

   ```ts
   function toEditorTool(tool: DrawTool): EditorTool {
     switch (tool.kind) {
       case 'text':
         return { kind: 'text' };
       case 'shape':
         return tool.shape === 'rectangle' || tool.shape === 'rounded' || tool.shape === 'ellipse'
           ? { kind: 'shape', shape: tool.shape }
           : 'select'; // the preset tools arrive with B4's EditorTool (SPEC-2 6.2)
       case 'line':
         return tool.line === 'line' || tool.line === 'arrow' || tool.line === 'rule'
           ? { kind: 'line', line: tool.line }
           : 'select';
       default:
         return 'select';
     }
   }
   ```
