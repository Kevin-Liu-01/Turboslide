# Audit: Tools, Tailor, the Assist panel, the agent surface, the templates and the inbox

The polish round's audit of the area "Tools: Tailor, the Assist panel, the agent surface (CLI and MCP), the templates and the inbox behind Advanced tools, the appearance setting, Preferences". Driven on 2026-09-28 against production https://www.turboslide.com (`main` at 877eb690) in headless Chromium through playwright-core 1.62.1 from the worktree, Node 24.13.0, at 1440 by 900 and 1280 by 800, device scale 2, at human speed (the mouse moved in steps, 40 to 90 ms per key, the browser's own double clicks). Three scratch decks were made from `/new` and driven through the product's own controls: `untitled-20260928-t674` (run 1, 306 s, 44 rows), `untitled-20260928-9s3q` (run 2, 255 s, 15 rows) and `untitled-20260928-gvep` (run 3, 57 s, 6 rows). Every deck was moved to the trash and deleted forever, two through File > Move to trash and the trash page, one (`9s3q`, whose editor no longer loaded while the Blob store throttled) through `deck.trash` and `deck.remove` with the bearer; `/edit/<id>` and `/deck/<id>` answer 404 for all three. The two templates the runs saved (`polish-audit-uq3s`, `polish-audit-catg`) are deleted; `template.list` on production reads `blank, gt-brand` again. The agent bearer came from `~/.config/turboslide/hosts.json` through the round's wrapper and appears in no file here. The CLI ran from the worktree as `node apps/cli/bin/turboslide.mjs`. The rows the matrix names for this area are not the measure here; the screen is.

Evidence is under `docs/gslides-parity/polish/audit-assist/`: the screenshots named by step (`01` to `124`), `rows.json`, `rows-2.json` and `rows-3.json` (every step with its expected and observed reading), `agent-surface.json` (the manifest, OpenAPI, llms.txt and MCP facts) and `scripts/` (the three drives, the agent reader, the cleanup scripts and their logs).

Copy rules of this file: "today" is a reading with the screenshot's name; the fix names the behaviour, the words and the file with its line; severity 3 means a seller calls it broken or jank, 2 a seller notices, 1 a person who looks closely notices; effort is 1 to 5.

## 1. Summary

### What a seller feels in this area today

The Assist button sits where Google draws Ask Gemini and Cmd+J opens a panel that looks finished: a first line, three starter rows and a box to type in (`02-panel-cmd-j.png`). Two of the three starters and the box ask a model this deployment does not have. Make it shorter shows "Asking the assistant" for 12.5 s, then the whole panel becomes one sentence, "The assistant is not set up on this Turboslide yet", and the starters and the box are gone until the panel is closed and opened again (`05-shorter-answer.png`, `06-panel-reopened.png`). A phrase typed into Search the menus that matches nothing offers "Ask the assistant" and lands the seller in the same dead end nine seconds later (`24-finder-ask-row.png`, `97-ask-row-answer.png`). The one starter that works, Tailor for a customer, is the best thing in the area: one dialog, one write, one Undo, the deck's name follows the customer (`14`, `16`, `17`). The dialog has visible seams: the count "3 places on 3 slides" is printed twice, a greyed checkbox nobody can tick sits in the middle, and after Apply the dialog stays open for 4.6 s reading "Not found in the text" for the name the seller just typed (`14-tailor-count.png`, `94-tailor-apply-sample-0.png`).

An agent's write arrives with a snackbar and Undo within a second, which Google has no equivalent for, but the sentence reads "Our renewal proposal covers the three r… became Our contract proposal covers the three…" and says nothing a person can act on (`91-outside-write-snackbar.png`). The agent surface itself is solid: the manifest lists 172 actions with 167 implemented, the MCP endpoint serves 161 tools, `deck pull`, `info`, `slides`, `export txt` and `export pptx` ran from the worktree against the pulled deck, and `logo search`, `template list` and `notifications` ran against the deployment. Two seams: the action table documents `turboslide assist propose` and `turboslide tailor` and the binary has neither command, and the agent transports answer status 500 for the assistant's "not set up" refusal where the panel's route answers 503.

Behind Advanced tools the parked features read as unfinished. Save as template holds a greyed Save for seven seconds with no words and closes with no confirmation (`33-save-template-snackbar.png`, `105-save-template-result.png`). Delete on the gallery card did nothing in run 1 for 30 s (`38`, `39`) and in run 2 removed the card, which came back on a reload; only the actions API removed each template. The bell opens Notifications and a second click does not close it (`40`, `41`). Notification settings save and reopen as None and read Comments for you after a reload (`42` to `45`). Tools > Preferences > Link detection is a checkbox with no effect: an address typed with it off became a link twice (`121-link-off-typed.png`). View > Appearance and the Brand kit's Appearance tiles work in both directions (`53` to `59`). A view link's page draws an Assist button that opened nothing when clicked (`124-viewer-assist.png`).

### The ten items to fix first

1. Do not offer what the deployment cannot do (item 1): the editor learns the assistant's mode at boot, the panel draws Tailor alone with one sentence where the model starters and the composer would be, and Search the menus offers no Ask row.
2. Make a deleted template stay deleted and a saved one confirmed (items 2 and 10): the gallery's delete and rename go through the same push and pull as the actions API, an instance never lists a folder the index dropped, and Save closes at once with the snackbar the code already names.
3. The inbox behind the switch either keeps its settings on the blob tier or does not offer them (item 15); the bell toggles like the comments glyph (item 4).
4. Pass Link detection to the editor (item 3): one prop.
5. One Tailor pass (items 5, 7, 11): the count once, no greyed checkbox, the dialog closed on Apply with the snackbar carrying the result.
6. Say what an agent changed (item 12): the changed words, or the slide alone.
7. The panel's words (items 8, 9): one line under the composer instead of four lines above everything, and a placeholder that fits its box.
8. No tooltip left on screen after the palette closes (item 13).
9. The CLI gains `assist` and `tailor` or the table stops naming them (item 14).
10. The viewer's Assist button either opens its sentence or is not drawn (item 6).

Features driven: 58 (section 5).
