# Return audit: formatting

Auditor for the area "Formatting: every text, paragraph, object and slide formatting row, core and parked", the return round, 2026-09-18, against production https://turboslide.vercel.app serving `1d3ba31` (the focus round's ship). Headless Chromium through `playwright-core` 1.62.1 from the repository's `node_modules`, Node 24.13.0, viewport 1440 by 900 at device scale 1. No source file was changed and no git write command was run. The scripts live under the auditor's scratchpad (`return/formatting/lib.mjs`, `audit-formatting.mjs`, `explore.mjs`, `assemble.mjs`, `render-table.mjs`) and import nothing from the repository but `playwright-core`. The evidence screenshots and the raw table (`rows.json`) are in `audit-formatting/` beside this file.

## 1. Method

Four scratch decks, each created from `/new` by typing the title through the product (the first write moves the address to `/edit/<id>`), each trashed through File > Move to trash and deleted forever on `/decks/trash` in a finally block, each answering 404 on `/edit/<id>` and `/deck/<id>` afterwards (`untitled-20260918-8gep` for the exploration of the control ids, `-lhcu` for the full battery, `-kreq` for the diagnostic and persistence pass, `-qfhf` and `-jt10` for the two heading passes; the first heading pass shortened its own title with undos pressed after refused writes, so it was driven again with an undo only after a write, and only the second pass counts).

Every row is driven through the product's own controls: the menus by `data-control` (`menubar.<id>`, `menu.<row id>`), the toolbar by its control ids, the colour plates by `toolbar.<op>.<token>`, the preset grids by `format.bulletsNumbering.<family>.pick.<preset>`, the Format options fields by `formatOptions.<section>.<field>` and the inspector's `block.<type>.<field>` rows, the runs by `data-run`. Human speed throughout: the mouse arrives in steps with a pause between them, keys land 40 to 90 ms apart, double clicks are the browser's own, a drag holds the pointer from down through the move stream to up. The click model is AMENDMENTS.md A1: one click selects an object, a double click opens its text, a double click inside the session selects a word. The switch Tools > Advanced tools is turned on first in every deck and the parked Format rows are read as present before the battery starts.

Every row applies one interaction, reads the stored block (`slide.get` through `window.turboslide.studio`, the block's `typography`, the text markup's inline flags, the `pos`), reads the drawn run (computed weight, size, alignment, line height, colour, the mark elements), then presses Cmd+Z with the object selected and reads again. A failed interaction was repeated three times before it was called broken; a pass on a later try is flaky; an interaction the script could not drive is not driven with the reason, and a disabled stub is not driven, never broken. The rows were driven on a text box placed by a click, a text box drawn by a drag, a rectangle from Insert > Shape with text typed into it, and the title of the title slide; a heading on a split layout was added in the heading pass. At the end of the diagnostic pass a kept set was applied through the product (Bold, a size step, Center, 1.5 spacing, an italic word, a red word, a superscript word and UPPERCASE on the first box; a bulleted list on the second; Green fill and Bold on the rectangle) and read back after a reload, in the show and in the shared viewer.

Two rows are re-judged by hand from their recorded evidence and say so in their evidence column: the Change theme row (the fresh deck's sheet was already dark on try 1, so the dark tile changed nothing and the light tile turned it light; on try 2 the panel went light to dark to light) and the three Format options field rows (every field wrote on every try; the failure was the undo half, measured in its own row). The counts of the table are computed from the rows.

The `before` column holds the focus audits' measurement of the same interaction before the parking, by file and row (`docs/gslides-parity/focus/audit-text.md`, `audit-arrange.md`, `audit-slides.md`), or "not measured".
