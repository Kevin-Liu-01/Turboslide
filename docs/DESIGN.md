### 1.3 What this round does not do

- It adds no runtime dependency to `/home`'s live core and no script library for scrollbars (OverlayScrollbars, 14,948 B gzip, is rejected: the CSS rule covers every request and the brand lint bans scroll libraries).
- It adopts no Radix primitive (35,001 B gzip for popover, dropdown and tooltip, a rewrite of `Menu.tsx` and `Tooltip.tsx` and of the tooltip contract) and no Radix Colors values (the brand's ink is 6.30 CIEDE2000 from Radix gray12).
- It does not replace the 21 outside click listeners with one hook; that is code tidiness with no visible change, left for a later round.
- It does not change a slide's grammar: the type ladder, the 500 weight cap, the 15 px floor, the square corners of everything on a slide and the General Translation theme's sheet (parity with Prototemplate `deck/parts/head.html`) stay as they are.
- It does not name Editorial or any second face: every theme is Inter.

### 2.3 The `Layer` primitive and the top layer

`packages/chrome/src/Layer.ts` (D1's) exports `useLayer(ref, { layer, open })` and the small manager behind it:

1. On open it sets `popover="manual"` on the element, `data-layer="<name>"` and `style.zIndex` from `LAYERS`, then calls `showPopover()`. On close it calls `hidePopover()`. `manual` keeps today's dismiss code in charge, so nested menus, Escape and outside clicks behave as they do now.
2. The top layer orders by opening, newest on top. The manager keeps the scale's order among the surfaces that are open: when a surface opens at layer L, every open surface whose layer is above L is hidden and shown again in ascending order in the same task (no frame passes between, so nothing flickers). Within one layer the newest is on top, so a submenu sits over its parent with no `+ level`.
3. The element stays where it is in the DOM. Inherited tokens (`.ts-overlay[data-theme]`, `:root[data-theme]`) and every selector through `.pt-viewer` keep applying; the top layer only changes how it paints, so the risk research-surfaces P1 named for a portal (selectors that stop matching) does not arise.
4. One rule in `tokens.css` resets the browser's popover styles at zero specificity before each plate's sheet draws it: `:where([popover]) { inset: auto; margin: 0; padding: 0; border: 0; background: none; color: inherit; overflow: visible; }`. A plate positions itself with `position: fixed` through `place()`.
5. Where `HTMLElement.prototype.showPopover` is absent, the primitive leaves the element in its DOM place with the scale's z-index, which is today's behaviour with ordered numbers. The browser floor is in question 12.
6. Focus is unchanged: `Dialog.tsx` keeps its Tab trap and `aria-modal="true"`, menus keep their roving focus.

The surfaces it carries, all through `useLayer`: the tooltip manager's one element, every `Menu` and `ContextMenu`, `PlateMenu` (account, roster, comment card menus), the font, colour, icon, weight, dash and line end pickers, the layout plate, the toolbar swatch plate, the insert and export menus, the chart grid menu, the sidebar row menu, the name prompt bar, `Dialog` (scrim and card), the float dialog, the search card, the help card, the export report, `Toast`, `Snackbar`, the hover preview, the slideshow layer and its shortcuts card, the presenter view's menus, the Sign in dialog and the `/decks` card menus and dialogs. The stage's own plates (comment cards, the Following plate, the queue plate, the selection chip) stay in the stage at their local order.

### 2.4 Placement

`packages/chrome/src/place.ts` (D1's) wraps `computePosition` of `@floating-ui/dom` with `strategy: 'fixed'`, `offset`, `flip`, `shift` with 8 px from the viewport edge (the margin the three functions use today), `size` for a menu's maximum height, and `autoUpdate` while the surface is open; the phone submenu rule of `placeMenu` (`Menu.tsx` 163 to 172) is one of its options. `placeMenu`, the tooltip's `place` and `anchoredAt` are replaced by it (D2). CSS anchor positioning replaces `place()` once the browser floor drops Safari 18 and older (question 12).

## 4. Type and numbers

### 4.1 The face

- The face is Inter 4.1 by Rasmus Andersson, the rsms/inter release file `packages/fonts/assets/InterVariable.woff2` ("Version 4.001;git-9221beed3", sha256 `693b77d4...a8e3`, the same bytes as `inter-ui` 4.1.1's `variable/InterVariable.woff2`), and its italic.
