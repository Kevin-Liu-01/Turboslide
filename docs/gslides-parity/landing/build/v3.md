### Interfaces V3 exports

- `playStep(target, step, options)` and `loopStep(step, customer)` from `live/step.ts` (6.3, R22):

  ```ts
  export type StepTarget = {
    /** the screen's line containers by width; the hero passes `narrow` alone (44 columns) */
    terminal: Partial<Record<PanelWidth, HTMLElement>>;
    /** the positioned wrapper of the slide the step changes: the ring and the flag are drawn in it */
    sheet: HTMLElement;
  };
  /** a step with its words chosen: `loopStep(HOME_LOOP.steps[i], customer)` or a chip's command */
  export type PlayableStep = { command: string; typedChars: number; answer: readonly string[]; landing: StepLanding };
  export type StepOptions = {
    /** clears the screen before the command (the hero's Restore) */
    clear?: boolean;
    /** called once the answer has printed and the beat has passed: sets the change, returns the element the ring travels to (null: no ring) */
    land(): HTMLElement | null;
    /** where the ring starts when the sheet has no ring yet (the whole slide by default) */
    from?: HTMLElement | null;
    band: SequenceBand;
    /** registers the step as a sequence of its band (the chips); the hero's loop passes false */
    track: boolean;
    onEnd?(): void;
  };
  export type StepHandle = { pause(): void; resume(): void; finish(): void; readonly done: Promise<void>; readonly length: number };
  export function playStep(target: StepTarget, step: PlayableStep, options: StepOptions): StepHandle;
  ```

  A paused step holds no timer, frame callback or running Web Animation (its frames are a function of its own `onFrame` clock); the ring and the flag are ink; `length` is the step's length in ms on its clock once it has landed (an estimate before).
- `openShow(container, slideId)` from `live/show.ts`: opens the show inside `container` on that slide, focus on its stage, and returns `{ close(): void }`; Escape and Exit close it and return focus to the element that had it.
