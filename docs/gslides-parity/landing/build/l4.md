- **M1, the boot script's place (`src/routes/home.tsx`, push 1).** The boot script is one inline script, the first child of `main#top`, before the speculation rules script, rendered only while `BOOT_SCRIPT !== ''` (empty until push 7):

  ```tsx
  {BOOT_SCRIPT !== '' ? (
    <script nonce={nonce} suppressHydrationWarning dangerouslySetInnerHTML={{ __html: BOOT_SCRIPT }} />

  ```

  Why there and not in the head: it adds `ts-intro` to `html` before any of `main` is parsed, so nothing of the hero paints in its end pose first, and it sets the visit sentence and the typing up inside its first `requestAnimationFrame` callback, which the browser runs before it paints the frame that first holds the subtitle; so the sentence never swaps after it paints (row `home.motion.hero`) and the script reads no layout. - **M2, `build-home-assets.ts --boot` (push 1, or before push 7).** `boot.ts` exports `bootSource(sentences)`, which returns `{ source, tables }`: the unminified script as one IIFE string with the three sentences and their gap tables inside it, and the `GapTable[]` of `boot.generated.ts`. The build minifies it with the minifier Vite carries (no new dependency) and writes the three exports:

  ```ts
  import { createRequire } from 'node:module';
  import { bootSource, BOOT_LIMIT_BYTES } from '../apps/studio/src/components/home/boot.ts';
  const vite = createRequire(join(ROOT, 'apps/studio/package.json'))('vite') as typeof import('vite');
  const { source, tables } = bootSource(HERO.visit);           // copy.ts, three sentences
  const script = vite.minifySync('boot.js', source, { compress: true, mangle: true }).code.trim();
  if (Buffer.byteLength(script) > BOOT_LIMIT_BYTES) throw new Error('the boot script is over 1.5 KB');
  // boot.generated.ts: BOOT_SCRIPT = script, BOOT_SHA256 = sha256(script), VISIT_GAPS = tables
  ```

  `--check` runs the same and compares the three values with the file. `bootSource` throws on a sentence over 50 characters or a last key after 3,970 ms, and `BOOT_LIMIT_BYTES` is 1,500 (the script read 1,497 bytes with today's three sentences).

- **M4, the field boxes (`HomeSheet`, `HomeField`, the canvas band; push 1).** Each `[data-field="hero|strip|canvas"]` box carries `--ts-still` (and the hero's `--ts-still-disc`) as a `url(...)` value L4 reads with `getComputedStyle(box).getPropertyValue('--ts-still')`, and holds two children: the still layer, which is the only masked element (a child such as `.ts-field-still`, or the box's `::before`), and one empty `<canvas aria-hidden="true">` that is not inside a masked element, sized to the box (`position: absolute; inset: 0; width: 100%; height: 100%; image-rendering: pixelated`).
