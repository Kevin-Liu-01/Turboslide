- `a1-<kind>-<gesture>-NN-<step>.png` and `gestures.json`, `gestures-frames.md`: the rectangle, rounded rectangle and ellipse drawn by a 12 step drag, placed by a click, resized from se and e, moved and rotated; `a2-text-*`, `a3-picture-*`, `a4-table-*`, `a5-chart-*` the same reader on a text box, a picture, a table (the se handle and the first column seam) and a column chart. Each drag has a `before`, a `down`, twelve `stepN` frames and `up+40`, `up+120`, `up+400`; the JSON carries `up+0` too. - `b01` to `b16` (light) and `d01` to `d16` (dark), `components-b.json`, `components-d.json`: the 3 by 3 table walked at human speed (inserted, one click, typed with Tab, a row and a column added and removed, the seam, the header range, Format options, resized and moved, reloaded, the show, the PDF as `b-table.pdf` and `d-table.pdf`), a table on a one-column slide (`b14` to `b16`); `b17` to `b52`: the six diagram kinds (the panel, inserted, a label edited, Cmd+D and Delete, resized).
