## Getting started

Open [turboslide.com/new](/new) to start a blank presentation. It is saved in this browser as you type, and there is no Save button.

<Steps>
  <Step title="Start a presentation">
    Go to [/new](/new), or pick a template from Your Presentations at [/decks](/decks).
  </Step>
  <Step title="Add and arrange slides">
    Press Ctrl+M to add a slide after the current one. Drag a card in the filmstrip on the left to
    move a slide.
  </Step>
  <Step title="Write on the slide">
    Click a text box and type. Click under the slide, where it reads Click to add speaker notes, to
    write what you will say.
  </Step>
  <Step title="Present it">Click Slideshow, or press Cmd+Enter (Ctrl+F5 on Windows).</Step>
</Steps>

## Agents

Every command in the menus is also an action that a program or an AI agent can run. The command line, MCP, HTTP and the page API are made from one table of actions, and each checks its input the same way.

```sh
turboslide info --json
turboslide slide new --layout split --after title
```
