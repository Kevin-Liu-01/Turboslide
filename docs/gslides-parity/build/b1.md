## 3. Decisions taken where the SPEC was silent, and deviations

1. **A Section header starts a section.** The validator requires an opener first in its section
   (severity 3), so `slide.new --layout opener --after X`, a duplicated opener and an imported
   opener start a new section right after the anchor's, taking the slides that followed the anchor
   (`insertAt` in store-actions.ts); `slide.applyLayout` to Section header on a slide that is not
   first in its section does the same split and reports the slide under `moved`. An anchorless
   insert into a section that has a header lands after the header. Apply layout therefore never
   refuses (SPEC 0.4), and the write always validates.
2. **`baseRevision` on the deck level actions.** `deck.copy`, `deck.trash`, `deck.restore` and
   `deck.remove` take the deck's revision the caller read (SPEC 7.5: every mutating action takes
   `baseRevision`; the coverage test also requires it); the CLI defaults it to the current one.
3. **The empty picture reference.** `shot.asset`, `pair.figures[].assets[]` and
   `details.items[].asset` accept `''` (`EMPTY_ASSET_REF`): the figure layouts insert it, the
   validator skips the reference check for it, and the editor draws the dashed "Click to add a
   picture" plate (B2, B4). Without it the figure layouts could not insert on a fresh deck.
4. **`table_size` in the validator, not in Zod.** The Zod schema keeps `min(1)` only; the cap and
   the ragged row are `validate.ts` checks so the issue code names the rule (SPEC 7.3).
5. **Whole box links refused on the grammar text blocks** (heading, paragraph, credit, rows, plain,
   refs, say, scales, spec, lang, ladder, swatches, panel, matrix): SPEC 7.2.7's refused column;
   the table is linkable as an object.
6. **The trash stamp bypasses the version log.** `deck.trash` writes `trashedAt` on `deck.json`
   without a revision bump (SPEC 7.2.5 says the field is never written through `deck.set`); undo
   is `deck.restore`. On Blob the mirror proves the new manifest through its etag (the fresh path
   of `pull`), not through a replayed record.
7. **`deck.copy` copies files directly** rather than through pack and unpack: the same validation
   (the copy is read back through `loadDeckDir`) with less machinery; the bundle path stays for
   transfers.
8. **Apply layout on a picture layout converts leftover lists and tables to one multiline
   paragraph each** (the plate takes no list blocks); leftover pictures beyond the background
   become figure blocks on the plate (a severity 2 `allowedIn` lint, never a refusal).
9. **Empty leftover placeholders are not appended** on apply layout and write nothing in the text
   export.
10. **`export.run --include-notes`** is parsed and warned about; the PPTX writer (B2) does not carry
    notes yet. `--include-skipped` is honoured now by filtering the slide ids before the writer.
11. **`text.replaceAll` replaces inside runs**, never inside a link URL or the GT mark, and treats
    `\n` as a character; the notes are replaced as plain strings.
