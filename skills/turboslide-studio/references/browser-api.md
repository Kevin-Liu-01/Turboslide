# Turboslide studio browser API

Generated by `pnpm generate:contracts` from `packages/schema/src/actions.ts`; do not edit by hand.

The adapter is `window.turboslide.studio`; it is ready after the `turboslide:studio-api-ready` event, whose detail is `describe()`. The ownership model is Glyphfield’s: the component that owns state registers an adapter with an `owner` element, and the getter resolves the last registration whose owner is connected and not under `[inert]`, `[hidden]`, `[aria-hidden="true"]` or `[data-active="false"]`. Controls are found by normalized accessible label (`aria-label`, `title`, `name`, `aria-labelledby` or the wrapping `<label>`) and by `data-control` id; inspector controls read `<block id>: <property label>` (`list: Size`) with `data-control="block.list.size"`. A missing label throws `RangeError`.

## Methods

| Method                  | What it does                                                                           |
| ----------------------- | -------------------------------------------------------------------------------------- |
| `version`               | The API version, 1                                                                     |
| `describe()`            | The active owner, its actions and whether source read and apply are supported          |
| `controls()`            | Visible interactive controls with accessible labels, data-control ids and values       |
| `activate(label)`       | Activates a control by accessible label or data-control id; RangeError when missing    |
| `set(label, value)`     | Sets a control by label or data-control id and dispatches input and change             |
| `readSource()`          | The exact current source document of the active owner                                  |
| `applySource(doc)`      | Applies a JSON string or object through the validator, then waits two animation frames |
| `invoke(action, input)` | Runs a standard action or delegates to the active owner                                |
| `download(artifact)`    | Saves a returned artifact with its deterministic file name                             |

## Standard actions

The six Glyphfield standard actions are handled by the API itself: `source.read`, `source.apply`, `controls.list`, `control.activate`, `control.set`, `artifact.download`. Everything else is delegated to the active owner.

## Completion

A resolved `applySource` or `invoke` is a React commit boundary, not a render: wait for the stage to re-render (two animation frames, then `document.fonts.ready`, then image decode) before reading pixels. Re-read the source after every apply; the validator may have canonicalized text.
