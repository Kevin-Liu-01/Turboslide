## Summary

### What works

With the switch on, the rulers and guides are whole: Show ruler and Hide ruler, a drag out of the ruler with its inch readout, Show guides, Add vertical and Add horizontal guide, Snap to guides on and off (a block dropped 4 px short of a guide lands on it with the row on and where it is dropped with the row off), Clear guides, and the right click rows on the empty canvas and on a guide (Delete guide removed it). The File surfaces that read or move decks work: From template gallery opens the home page at the templates strip, Open lists and filters the studio's decks and opens a bundle as a new deck, Import slides copies slides from another deck or from an uploaded bundle, Details reads the deck's facts, the web page and bundle downloads arrive with their notices, Version history's Show changes flips. The View toggles work as toggles: Grid view on and off (from the menu and the bottom bar), Show filmstrip, Mode, Full screen, Appearance, Live pointers, Snap to grid, the four Comments display radios. In Tools, Check slides lists real suggestions with Fix. Edit > Select none clears the object and the filmstrip selection. Help Turboslide improve reaches the repository's new issue form. The Notifications bell opens its panel with the settings link, the account menu opens with its rows, the roster lists the people with their slide and Go to slide jumps. Deleting a deck made from a bundle leaves the original untouched.

### What is broken, with the mechanism seen

- Grid view cannot do its job: one click on a tile leaves the grid and opens the slide (as before the parking, audit-slides row 75), and no drag starts on a tile under three recipes (draggable="true" with HTML5 drag handlers, no is-dragging class, no drop marker, the order unchanged; audit-slides row 78). The seller's bulk reorder task fails in the grid.
- Plain Text (.txt) download does nothing: no file, no anchor, no snackbar, no console error in six tries across two runs, where the focus audit got a 28 B file on ec61c6b (audit-export row 21). The client makes a blob anchor from result.text; nothing observable follows the click now.
- JPEG and PNG open a tab that answers 401 "bearer token required" (unchanged, audit-export rows 22 and 23).
- Publish to web forgets itself: the link is minted and answers 200, but /deck/<id>?present=1 answers 200 without the token as well (shadow authorization), reopening the dialog reads "not published" with Publish and never offers Stop publishing, and the minted link keeps answering. The dialog seeds its state from access.published, which the shell does not carry.
- Make a copy > Selected slides makes the copy on the server (GET 200) and shows nothing: no new tab, no snackbar, the address unchanged; a second click answers "exists already; pick another name" (audit-decks row 37 saw the card menu version flaky).
- Change name and Change avatar close without an error and change nothing, before or after a reload; after the reload the label was a fresh generated one. account.setName and account.setAvatar write the principal record; the chrome keeps the identity read at page load and the anonymous principal is not read back.
- Notification settings does not keep the choice: None checks and Save closes, reopening and a reload read "Comments for you" again.
- Activity dashboard reads "No activity yet" after a deck was created, titled, given slides, guides and a publish; the Viewers tab is a disabled stub.
- Underline errors flips data-spellcheck on the root and nothing reads it: the open text run keeps spellcheck="true", the notes field too, zero CSS rules name the attribute.
- Show all comments does not open the Comments panel its doc promises (on a deck without comments).
- The deck's name is taken from the heading when the first autosave lands, not when the title is done: two decks of three typed at human speed got "Pipeline rev" and "P" as their name in the title row, in Details and in the file names while the heading read the full title (audit-export row 2 saw "Acme pricing" the same way).
- A guide drag commits only when the press rests before the pointer moves (three fast drags snapped back to 800, one slow drag with a 300 ms hold moved the guide to 600; audit-arrange row 70 saw it work).
- Forget this browser on a fresh draft answers "No deck <draft id> in the Blob store" and stays open.
- The Slideshow split button reads as two controls because the seam colour --pt-edge equals the button ground and each half keeps an 8 px radius at the join (gap 0, both halves rgb(242, 242, 240)); Share beside it is an outline button of the same height with a hairline in rgba(242, 242, 240, 0.22).

Not driven: Sign in (no provider on production, the row is absent), Sign out (nobody signed in), Follow (offered only to account participants with the editor role; a second anonymous browser lands as a viewer today, which also means audit-present row 26's open editor for a stranger is closed), the chip click's jump (the viewer could not be moved off slide 1; the roster proves the same Go to slide), the PowerPoint import (both dialogs refuse a .pptx with a clear sentence; the importer does not exist).

### What to bring back and what it needs

Return as they are (they work and a seller uses them): the rulers and guides with Snap to guides (View > Show ruler, Guides, Snap to; the right click rows), From template gallery, Open, Import slides (from a deck and from a bundle), the bundle download, Details, Show changes, Select none, Show filmstrip, Mode, Full screen, Appearance, Live pointers, Check slides, Help Turboslide improve, the Notifications bell, the roster's Go to slide, and the web page download (one look at the first attempt being cancelled in both runs).

Return after fixes, in the order a seller feels them: the grid (a click selects and a double click opens, per A1; a pointer drag that reorders, the filmstrip's own drag is the model) since bulk reordering is the grid's purpose; the deck name (name the deck when the title session ends, or follow the heading until renamed by hand) since it leaks into every download and Details; Publish to web and Embed in a site (read the published record on open, offer Stop publishing, gate the player by the token once authorization enforces); Make a copy > Selected slides (open the copy or say where it is); the JPEG and PNG downloads (a download token for the render, as the web page has); Plain Text (hand the text through the download route with its notice, and say something when the action answers empty); the guide drag (start the drag on the first move after a press); Notification settings (persist the level); Change name and Change avatar with the account menu (refresh the identity from the action's answer and persist the anonymous name); Show all comments (open the panel on the pick); the Slideshow split button (one visible seam token, the radius on the outer corners only, and Share matched in height and weight).

Stay parked: Sign in, Sign out, Sessions and Forget this browser until production has accounts; Follow until account participants exist; Activity dashboard until the feed fills on an anonymous production; Underline errors until it reads something; Show sections (no effect on a one section deck); the Tools > Advanced submenu (designer's and debugger's tools; Render this slide not driven cleanly); Agent access (the agent user's, not the seller's). Not features: the switch itself and the Later stubs (Present on another screen, ODP, SVG, Page setup).
