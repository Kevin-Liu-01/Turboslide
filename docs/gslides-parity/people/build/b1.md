### Notes

- A signed in account without a typed name gets no name prompt on its first edit: the prompt's condition is `identity.trust === 'label'` (`controller.tsx`, the polish round's lines) and a verified identity is not a label. Its own chip reads the account's label with the badge; "Change name" is the way to a name. A question for Kevin beside 8.1 rather than a change in this lane.

- The room's principal store is a file store even on a Redis deployment (room.ts `state()`, unchanged); the account's record on the session branch is read through the runtime's store, which is the same file store on a checkout and on production today.
- `people.chip-tooltip-trust` on a link visitor's role word: see R2.
