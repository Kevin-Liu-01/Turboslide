# Google Slides present mode and keyboard shortcuts

Research report 04 for the Google Slides parity round. Written 2026-09-11 for the Turboslide designers. Every fact below comes from a public page read on 2026-09-11; the sources are numbered and listed at the end with their URLs. Nothing was signed in to, and no Google artwork or icon was copied. Claims that could not be confirmed from a public page are marked "unverified" in place and repeated in the last section.

Scope: (a) how presenting works in Google Slides on a computer (the Slideshow split button, the present mode toolbar, the presenter view window, the Q&A audience page, captions, autoplay, the pen tool, presenting into Google Meet, and the keys that work while presenting) and (b) the complete editor shortcut list as Google publishes it for Windows, Mac and Chrome OS.

Notation: "Cmd" stands for the Mac command key (Google writes it as the ⌘ symbol). "Option" is the Mac alt key. A chord written "hold Ctrl + Alt, press u then a" means the modifiers stay down while two letters are typed in sequence. Where a key differs on Chrome OS, the Chrome OS value follows the Windows value in the same cell. Source tags such as [G1] and [T3] point at the numbered list in the final section.

Method note: the in-app browser pane refused to open docs.google.com, so no live look at the current slideshow toolbar was possible. Positions and orders therefore come from Google's help text plus dated third-party walkthroughs, and the dates of those walkthroughs are given so the designers can judge freshness.

## Part A: present mode

### A1. Where presenting starts: the Slideshow split button

The Slideshow control sits in the top right of the editor header, next to the Share button. It is a split button: the main part starts the slideshow from the current slide, and a down arrow beside it opens a menu of alternatives. A separate Meet button, also at the top right, brings a Google Meet call into the editor.

### A3. The present mode toolbar (bottom left)

Google's help says: "When you present, you can choose more options from the toolbar at the bottom of the presentation window" and lists what it offers: select slides to present from a list, open Presenter view, turn on the laser pointer, print the presentation, download the presentation in PDF or PPTX format, and (in a separate section) auto-advance and the pen tool. The two dated walkthroughs (May and September 2021) describe the same layout: previous arrow, slide number box, next arrow, then a three-dot options menu at the right end. Google redesigned this toolbar in spring 2021 to the compact form described here.

## Part B: editor keyboard shortcuts

Google's published list lives on one help page with three tabs (PC, Mac, Chrome OS) [G1]. The page opens with three rules: Ctrl + / (Windows, Chrome OS) or Cmd + / (Mac) opens the in-app shortcut list; Alt + / (Windows, Chrome OS) or Option + / (Mac) opens Tool finder; and menu access keys work by opening a menu from the keyboard and typing the underlined letter of an item (Google's example: on a Mac press Ctrl + Option + i for Insert, then i for Image). The page warns that some shortcuts might not work for all languages or keyboards.

Google groups the published list as: Common actions, Film strip actions, Navigation, Menus, Comments, Text, Move and arrange objects, Presenting, Video player, Screen reader support. The brief's names map onto these as follows: "Editing" is Common actions plus Film strip actions plus Comments, "Moving and arranging objects" is Move and arrange objects, "Formatting text and objects" is Text, "Navigation" is Navigation, "Menu access" is Menus, and "Screen reader shortcuts" is Screen reader support. The group headings used inside the Ctrl + / dialog itself could not be checked without opening the editor and are unverified; the tables below keep Google's help-page grouping.

Row conventions: a cell holding two values separated by "or" means either key works. "Chrome OS:" inside a Windows cell gives the Chrome OS value when it differs. "(no Mac row)" or "(no Chrome OS row)" means Google's page has no such row on that tab.

### B10. Platform differences worth designing for

The Mac tab is the only one that lists a "from beginning" present shortcut (Cmd + Shift + Enter) and the only one that lists Slide and Arrange menu keys. The Windows tab is the only one with a revision history shortcut and a "play the selected video" row. Chrome OS drops the Page Up and Page Down film strip keys, uses Alt + Shift + . and , for the side panel, uses Backspace for Delete, and adds Shift + Click for "Add to selection". New slide is Ctrl + m on all three platforms, including Mac, which is the one Cmd-less shortcut in the Common actions group. Strikethrough is Cmd + Shift + x on Mac but Alt + Shift + 5 on Windows and Chrome OS. Find and replace is Cmd + Shift + h on Mac but Ctrl + h on Windows and Chrome OS. Hide or show menus is Ctrl + Shift + f on every platform, and the same combination is reported by third parties as the present-mode full-screen toggle, so the two must not collide in a port.

## Part C: notes for the Turboslide design

These are the behaviours a Google Slides user will expect from Turboslide's present route, drawn from the tables above.

1. The header needs a Slideshow split button at the top right with the menu order Presenter view, Start from beginning, Present on another screen (disabled when unavailable), Presentation display options. Ctrl + F5, Cmd + Enter and Cmd + Shift + Enter should map to it.
2. Present mode is full screen from the current slide, click or Right arrow to advance, Esc to leave, with a hover-revealed toolbar in the bottom left: previous, slide number that opens a slide list, next, then an options menu holding speaker notes, auto-play with the interval submenu and Loop, laser pointer, captions preferences, full screen toggle, pen tool, and a More group with Q&A, download PDF and PPTX, print, keyboard shortcuts, and stop presenting.
3. The keyboard map inside present mode is fixed by Google: arrows, number plus Enter, Home, End, s, a, l, b or ., w or ,, Ctrl or Cmd + P, Ctrl or Cmd + Shift + C, F11 or Cmd + Shift + F, Esc, any key to return from a blank slide. Turboslide's viewer should honour every row in A10.
4. Presenter view is a second window with a timer (Pause, Reset), the current slide with a slide list dropdown and Previous and Next previews, a Speaker notes tab with plus and minus font size buttons, and an Audience tools tab. Q&A, captions and Meet integration need services Turboslide does not have; the report records them so the menu can show them as unavailable or omit them deliberately rather than by accident.
5. The editor shortcut dialog (Ctrl + / or Cmd + /) should carry the B1 to B9 rows with the Mac and Windows columns, because sales users switch between the two.
