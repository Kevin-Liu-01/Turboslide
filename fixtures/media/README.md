# Media fixtures

The synthetic audio and video files of gslides-parity SPEC-5 3.9 and R11 8.3, generated once by `node fixtures/media/generate.mjs` on 2026-09-15 (ffmpeg 8.1.2 from Homebrew, Node 24.13.0) and committed; the check chain never runs ffmpeg (MILESTONES-5 rules). Every file is a test pattern (a 440 Hz sine, ffmpeg's `testsrc` bars), so no licence question arises. `facts.json` is ffprobe's reading of every accepted file (the duration in milliseconds, the streams with codec, size, sample rate and channels) with the byte count and sha256 per file; `packages/store/src/media/*.test.ts` compare the parsers against it (duration within 20 ms) and refuse to run against a changed file. `node fixtures/media/generate.mjs --facts` rewrites `facts.json` from the files present without touching them.

## Accepted

| File                      | How it is made                                                                                                                                                       | Exercises                                                                            |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `tone-1s.wav`             | written by the script: PCM 16 bit, mono, 8 kHz, one second of a 440 Hz sine, 16,044 bytes                                                                            | the sniff, the WAV parser, the show e2e, the export check                            |
| `tone-1s-extensible.wav`  | the same samples under `WAVE_FORMAT_EXTENSIBLE` (tag `0xFFFE`, the PCM sub format GUID)                                                                              | the sub format read                                                                  |
| `tone-1s-float.wav`       | IEEE float 32 bit (tag 3) with a `fact` chunk                                                                                                                        | the float form, a chunk before `data`                                                |
| `tone-1s-list.wav`        | PCM with a `LIST` chunk of odd length before `data`                                                                                                                  | the pad byte rule                                                                    |
| `tone-1s.mp3`             | `ffmpeg -i tone-1s.wav -c:a libmp3lame -b:a 32k tone-1s.mp3` (MPEG-2.5 Layer III at 8 kHz, ffmpeg's `Info` header and ID3v2.4 tag)                                   | the tag skip, the `Info` header, the LAME delay and padding                          |
| `tone-cbr.mp3`            | the same with `-write_xing 0 -id3v2_version 0`                                                                                                                       | the frame walk with no header (ffprobe reads 1152 ms: sixteen frames of 576 samples) |
| `tone-vbr.mp3`            | `ffmpeg -i tone-1s.wav -ar 44100 -ac 2 -c:a libmp3lame -q:a 9 tone-vbr.mp3` (MPEG-1 Layer III, a `Xing` header)                                                      | the `Xing` frame count, the MPEG-1 tables                                            |
| `tone-id3.mp3`            | written by the script: an ID3v2.4 tag with the footer flag set (one `TIT2` frame, 64 bytes of padding, the `3DI` footer) in front of `tone-cbr.mp3`                  | the footer rule of the tag skip                                                      |
| `tone-1s.m4a`             | `ffmpeg -i tone-1s.wav -c:a aac -b:a 48k -movflags +faststart tone-1s.m4a` (brand `M4A `)                                                                            | the ISOBMFF parser on a sound track alone, the m4a decision                          |
| `bars-1s.webm`            | `ffmpeg -f lavfi -i testsrc=size=320x180:rate=10 -f lavfi -i sine=frequency=440:sample_rate=48000 -t 1 -c:v libvpx-vp9 -b:v 200k -c:a libopus -b:a 48k bars-1s.webm` | the EBML parser, the poster capture in Chromium, the show e2e, the export check      |
| `bars-live.webm`          | the same with `-live 1 -f webm`: an unknown Segment size, no `Duration`, no `Cues` (the shape a MediaRecorder writes)                                                | the `durationMs: null` path (`recorded.webm` proper is captured by the e2e on day 7) |
| `bars-1s.mp4`             | `ffmpeg <bars> -c:v libx264 -preset veryfast -pix_fmt yuv420p -c:a aac -b:a 48k -movflags +faststart bars-1s.mp4`                                                    | the ISOBMFF parser with `moov` before `mdat`; the sniff and content type checks      |
| `bars-1s-nofaststart.mp4` | the same without `-movflags +faststart` (`moov` after `mdat`)                                                                                                        | the parser reaching a `moov` at the end of the file                                  |

## Refused

| File             | How it is made                                                            | Sentence                                                                                     |
| ---------------- | ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `tone-adpcm.wav` | `ffmpeg -i tone-1s.wav -c:a adpcm_ms tone-adpcm.wav`                      | the WAV parser names the MS ADPCM tag                                                        |
| `bars-1s.mov`    | `ffmpeg <bars> -c:v libx264 ... -c:a aac -f mov bars-1s.mov`              | "A QuickTime (mov) file is not accepted. Save it as mp4."                                    |
| `tone.ogg`       | `ffmpeg -i tone-1s.wav -ar 48000 -c:a libopus -b:a 48k -f ogg tone.ogg`   | "An Ogg file is not accepted. Convert it to mp3 or m4a."                                     |
| `bars.mkv`       | `ffmpeg <bars> -c:v libvpx-vp9 -c:a libopus -f matroska bars.mkv`         | "A Matroska (mkv) file is not accepted. …"                                                   |
| `tone.flac`      | `ffmpeg -i tone-1s.wav -c:a flac tone.flac`                               | "A FLAC file is not accepted. …"                                                             |
| `tone.aac`       | `ffmpeg -i tone-1s.wav -c:a aac -b:a 48k -f adts tone.aac`                | "A raw AAC (adts) file is not accepted. …"                                                   |
| `bars.avi`       | `ffmpeg <bars> -c:v mpeg4 -c:a mp3 -f avi bars.avi`                       | "An AVI file is not accepted. …"                                                             |
| `webm-as.mp4`    | written by the script: the bytes of `bars-1s.webm` under an mp4 name      | the bundle scan's name rule: "the bytes are a webm file, not mp4"                            |
| `truncated.mp4`  | written by the script: the first 4,096 bytes of `bars-1s-nofaststart.mp4` | "The mp4 file could not be read: no moov box: the file is truncated or still being written." |

`<bars>` stands for `-f lavfi -i testsrc=size=320x180:rate=10 -f lavfi -i sine=frequency=440:sample_rate=48000 -t 1`. The encoders this ffmpeg build offers decided two rows: `tone.ogg` holds Opus (`libvorbis` is not built in) and `bars.avi` holds MPEG-4 part 2 with MP3. The file over the cap by declared size (R11 8.3) is a number in the intake's test, not a file.
