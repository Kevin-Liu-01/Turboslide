### 6. Decisions this lane took, for the integrator and the ship note

- The Colors group's six swatches pick the kit role the shader takes as its ground and write `/preset` (the role's palette preset), so a `brand.set /colors/*` recolours the shader through the preset and re keys the frame; a Custom hex writes the ground uniform and `/palette: 'custom'`. Storing hexes in `uniforms` would have frozen the kit's colours into the block.
- `applyControls` leaves `u_scale` alone (Glyphfield scales it from amplitude, frequency and detail); Frequency, Amplitude and Detail move the named uniform groups alone, so a control does what its sentence says.
- Brightness scales the entry's colour uniforms where no `u_brightness` exists, so the control moves every shader and the still equals the editor at rest (a CSS filter would not reach the capture).
- The frame key hashes the seven palette values (the six roles and the figure colour) and the aspect at two decimals, without the pixel size and the backend (5.5); a frame captured before the round has no key and is stale by that absence.
- `shader.list` names the stills by file (`preview`, `presetPreviews`), not by URL: the browser builds the URL through `shaderPreviewUrl` (a Vite asset), and a URL an agent can fetch waits for a route or R11's function assets.
- The material label's CSS rule stays in `block-css.ts` (B3's file, request R10); it matches nothing.
