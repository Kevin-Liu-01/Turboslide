---
title: The editor
description: The parts of the editor window, what each menu holds, and where to find speaker notes, Find and replace and Version history.
---

The editor opens at `/edit/<id>` for a presentation you own or can edit, and at `/new` for a new one. It has four areas: the title row and the menus at the top, the toolbar under them, the filmstrip on the left and the slide in the middle. Speaker notes sit under the slide.

## The title row

The title row shows the presentation's name. Click the name to rename it. On the right are the people who have the presentation open, Share and Slideshow.

- **Share** opens the sharing dialog: the view and edit links and the people you invited by name.
- **Slideshow** presents from the current slide. The arrow beside it holds Presenter view and Start from beginning.

## The menus

Every command is a row in one of nine menus. Help > Search the menus (Alt+/) finds a row by its name.

| Menu    | What it holds                                                                                                                                                             |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File    | New presentation, Open, Import slides, Make a copy, Share, Download, Rename, Move to trash, Version history, Details and Print.                                           |
| Edit    | Undo, Redo, Cut, Copy, Paste, Paste without formatting, Delete, Duplicate, Select all, Select none and Find and replace.                                                  |
| View    | Slideshow, Zoom, the ruler, guides, snapping, comments, live pointers, speaker notes, the filmstrip, the editing mode and Full screen.                                    |
| Insert  | Images and logos, a text box, shapes, a table, a chart, a diagram, word art, lines and connectors, a link, a comment, a new slide, slide numbers and an animated pattern. |
| Format  | Text, alignment and indents, line spacing, lists, tables, images, borders and lines, Format options, Clear formatting and Alt text.                                       |
| Slide   | New slide, Duplicate slide, Delete slide, Skip slide, Move slide, Change background, Apply layout and Change theme.                                                       |
| Arrange | Order, Align, Distribute, Center on page, Rotate, Group, Ungroup and Regroup.                                                                                             |
| Tools   | Preferences, Tailor for a customer, Check slides and Advanced tools.                                                                                                      |
| Help    | Search the menus, Help, Help Turboslide improve and Keyboard shortcuts.                                                                                                   |

A row that cannot run on the current selection is grey, and its tooltip says why.

## The toolbar

The toolbar starts with the same controls on every selection: Search the menus, New slide with its layout arrow, Undo, Redo, Print, Paint format and the zoom box. After a divider it shows the controls for what is selected: text controls for a text box, crop and replace for a picture, fill and border for a shape. Point at a control to read its name and its key.

## The filmstrip

The filmstrip on the left shows every slide as a card, in order.

- Click a card to show that slide. Shift click selects a range and Cmd click (Ctrl click on Windows) adds one card.
- Drag a card to move the slide. Cmd+Up and Cmd+Down (Ctrl+Up and Ctrl+Down on Windows) move the selected slides one place.
- Right click a card for New slide, Duplicate slide, Delete slide, Skip slide and the layouts.
- A skipped slide stays in the filmstrip, shaded, and leaves the slideshow and the downloads.

View > Show filmstrip hides and shows the filmstrip.

## The slide

Click an object on the slide to select it. Drag it to move it, drag a handle to resize it, and type to replace the text of a selected text box. Shift click adds an object to the selection, and a drag on an empty part of the slide selects every object it touches.

- Arrow keys nudge the selection one pixel at a time; Shift and an arrow nudge it by a larger step.
- Cmd+D duplicates the selection, Delete removes it, and Cmd+Z undoes the last change.
- Right click an object for Cut, Copy, Paste, Order, Align and the commands for that kind of object.
- Format > Format options opens a panel with the size, position and every setting of the selection.

The zoom box on the toolbar and View > Zoom set the zoom from 25% to 1600%. View > Zoom > Fit shows the whole slide.

## Speaker notes

The notes pane under the slide holds what you will say for that slide. Click where it reads Click to add speaker notes and type. Drag the line above the pane to make it taller. The notes show in Presenter view and can be included in a PDF or PowerPoint download. View > Show speaker notes hides and shows the pane.

## Find and replace

Edit > Find and replace (Cmd+Shift+H, or Ctrl+H on Windows) finds text on every slide and in the speaker notes. Type the text to find and the text to put in its place. Next and Prev step through the matches, Replace changes the current one, and Replace all changes every match as one step that Undo reverses.

## Version history

Every change is saved as you make it, so there is no Save button. File > Version history > See version history (Cmd+Option+Shift+H) lists the saved versions with the time and the person who made each change. Click a version to see the presentation as it was, and click Restore this version to bring it back. File > Version history > Name current version gives the current version a name, so you can find it later.

## Modes

View > Mode switches between three modes:

- **Editing** shows the handles, the notes pane and Format options.
- **Commenting** lets you add and answer comments without moving anything.
- **Viewing** is read only.

A person you shared the presentation with for viewing or commenting gets the matching mode.
