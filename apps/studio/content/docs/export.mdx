---
title: Download and export
description: Download a presentation as PowerPoint, PDF, pictures, a web page or a Turboslide file, with or without speaker notes and skipped slides.
---

Choose **File > Download** and pick a format. Every download is made from the same renderer as the editor, so the file shows what you see on the slide.

## Formats

| Format                       | What you get                                                                                                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Microsoft PowerPoint (.pptx) | A PowerPoint file. Pictures, the default, draws each slide as a picture, so it looks exactly like Turboslide. Editable text keeps the text as text you can change in PowerPoint. |
| PDF Document (.pdf)          | One slide per page.                                                                                                                                                              |
| JPEG image (.jpg)            | The current slide as a picture.                                                                                                                                                  |
| PNG image (.png)             | The current slide as a picture.                                                                                                                                                  |
| Web page (.html)             | One file that opens in any browser and presents the slides.                                                                                                                      |
| Turboslide file (.zip)       | The whole presentation with its pictures, which File > Open and Import slides read back.                                                                                         |

The web page and the Turboslide file are under File > Download > More formats.

## Options

**File > Download > More formats > Download options** opens the download dialog with the file type and its options:

- **Include speaker notes** adds the notes to a PDF or a PowerPoint file.
- **Include skipped slides** keeps the slides you skipped.

## PowerPoint: Pictures or Editable text

<Tabs>
  <Tab title="Pictures">
    Each slide is a picture of the slide as Turboslide draws it, so the file looks the same on every
    computer. The words are kept in the file as hidden text, so they can still be searched and
    selected, but not edited.
  </Tab>
  <Tab title="Editable text">
    Text stays text, so it can be changed in PowerPoint. Each text box keeps its place and its line
    breaks; icons, diagrams and pictures travel as pictures. The text is drawn by PowerPoint, so the
    letters can differ slightly from Turboslide's.
  </Tab>
</Tabs>

## Long presentations

On turboslide.com a presentation longer than 60 slides is exported in batches of 60. The download dialog shows how far it has got, and the file arrives when the last batch is done. A batch that fails is retried on its own.

## Print

**File > Print** (Cmd+P) opens the print preview, one slide per page. **File > Print settings and preview** shows the options first.
