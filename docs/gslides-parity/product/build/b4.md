### 2. How a row of a control that is not built reads

PRODUCT.md 8.1: "a row of a control that does not exist is not driven". The walk's steps check the control before they drive and answer `t.notBuilt(control, lane)` when it is absent, so the ledger reads "not driven: not on this build: panel.brand (docs/PRODUCT.md 7.1, B5a)" and never a false failure; a spec skips with the same sentence. Once a lane lands its control the same driver judges it without an edit.
