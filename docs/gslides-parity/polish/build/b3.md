### Requests to B1 (`packages/viewer/src/Editor.tsx`, `Sheet.css`, `Gestures.tsx`, `Selection.tsx`, `InlineText.tsx`, `packages/chrome/src/Overlay.tsx`, `Pickers.css`, `inspector/format-sections.ts`)

1. Item 24, `Sheet.css`: the wrapper of a line kind takes no pointer. B3's `primitives.ts` writes the class `is-line` on the svg root of every line kind (line, arrow, elbow, curved, curve, polyline, scribble), sets `pointer-events: none` inline on that svg, and adds one transparent hit path (`<path class="hit" data-hit="stroke" ... pointer-events="stroke" stroke-width="12">`) over the drawn stroke. The `.free[data-free]` wrapper still takes the press for its whole box (`block-css.ts` line 149 gives it `pointer-events: auto`, and `resolveBlock` reads `.free[data-free]`), so the wrapper needs one rule in `Sheet.css`:

   ```css
   /* a line kind's hit area is its stroke (docs/POLISH.md item 24): the wrapper takes no press,
      the svg's hit path does, so a press inside a connector's box lands on the shape under it */
   .ts-stagewrap .free:has(> svg.shape.is-line) {
     pointer-events: none;
   }
   ```

   Nothing else changes: `resolveObject` over `e.target` answers the shape or the sheet under the box because the browser's hit test does. The line's chip and end handles keep their own pointer events.

2. Item 27, `Editor.tsx` `followAfter` (line 1880) or the free-move gesture's end (line 3207's `commitCanvas` call for `free-move`): a connector moved by its body detaches from every target that did not move in the same write. B3's `connect.ts` exports

   ```ts
   export function detachMovedConnectors(
     slide: Slide,
     movedIds: ReadonlyArray<BlockId>,
   ): Mutation[];
   ```

   which answers one `block.set /connect` per moved connector whose `start` or `end` names a block outside `movedIds` (the value is the remaining attachment, or no value when both go). Call it from the free-move gesture's end and the arrow key nudge only, with the moved ids, after `followConnectors`; never from the line-end gesture (that one just wrote the attachment) and never from a resize. A selection that moves A, B and the connector together keeps the attachments, as Google does.
