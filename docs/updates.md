# Updates

The release notes of Turboslide, newest first. An entry names the date, what changed in the default view and where the evidence is; the counts a release passed are in the release note it names and in the README section "What works today", which is rendered from the test matrix and never typed here.

## 2026-09-23, the features round, ship one

The round adds what a seller and a marketer reach for on a slide (docs/FEATURES.md): tables, charts, diagrams, word art and labelled shapes edited in place; Rasmus Andersson's Inter 4.1 in both files and eight more families; a logo picker over thesvg.org. Kevin's words for the round: make the ui for editing stuff like tables and diagrams much more intuitive and easy; make sure we are using the right rsms Inter and add a few more fonts; integrate thesvg.org for easy logo adding and searching. Ship one is objects, fonts and logos; ship two, the shader library with Glyphfield's controls, follows in its own run. The ship is `9d21394` on `main`, live on `https://turboslide.vercel.app` since 11:27Z on 2026-09-24 (deployment `dpl_441AUoH4Dmo4DBsKWsVbmBCRJp65`), after two gate runs on the enforce preview built from the tree and one on production, under the parked list `docs/gslides-parity/focus/ship-f1afe1e.json`.

What changed:

- Tables. One click on a cell of an unselected table selects the table and places the caret in that cell, and a drag from inside still moves the table, because the gesture is decided at the move threshold; a drag from a cell selects a range, and Bold, Italic, Underline, Strikethrough, the text colour, the size steps and Align on a range or on the whole table write every cell in one commit with one Undo. A printable key on a selected table appends in the cell last touched; the arrow keys cross cells, Tab and Shift+Tab move between them, and Shift with an arrow extends a range. The Table section leads Format options with one Height field for the selected rows and a Distribute rows button; three tab separated rows pasted with nothing selected insert a table, and the same rows pasted into an open cell fill the cells from there.
- Charts. A double click on a chart opens Format options on the Chart data section with the first value cell active; a click on a bar, a point or a slice of the selected chart makes its cell active and the readout shows the value; an Edit data button sits under the selected chart. Every key pressed inside the grid is the grid's, so typing on a cell edits it and Escape stays in the panel; the series swatch and the remove controls are visible; Legend > None from the toolbar writes none; each chart property is listed once; tab separated rows pasted into the grid replace the data and the chart redraws.
- Diagrams and shapes. A diagram step is one shape with its own label, so a drag moves the step with its label and the connector follows, and one Delete removes it; a double click on a label opens it, Tab moves to the next label in the group, Shift+Tab back, Enter on a selected group opens the first label. A shape's label is centred by default.
- Fonts. The italic is Inter 4.1's file beside the 4.1 upright, and the release and licence links the code names answer; Inter Fallback (Arial with matched metrics) is second in every stack; the display features cv11 and ss01 apply to Inter alone, so another display face draws its own forms; table cells, chart labels and the status board use tabular figures, and Format options carries a Tabular figures row for any block. Eight families join the catalog under the OFL 1.1: Geist, Geist Mono, Instrument Sans, Manrope, Bricolage Grotesque, Schibsted Grotesk, Newsreader and Fraunces, each in the Font dropdown drawn in its face, in More fonts with a licence line, and in the PDF and the PowerPoint file.
- The logo picker. Insert > Logo (and Search the menus answering "logo") opens the Logo dialog: Your brand first (the kit's logo and the deck's own logo assets), Recent (the last twelve picks in this browser), then results from thesvg.org's index as the seller types, each tile drawn on paper and on ink with its name under it. The picker chooses the variant for the deck's appearance; a mono mark under an open licence is tinted with the kit's text colour; the licence reads in the seller's words ("Free to use", "The brand's own terms"). One click inserts the mark as a stored asset at the logo size in the largest free rectangle of the body slot, selected, one Undo; "Use as this presentation's logo on every slide" puts it in the kit's slot; Replace image > Logo on a picture's right click menu swaps a placed picture for a mark; Tailor's Find the customer's logo does it for a whole deck. The server holds the index per instance and rebuilds it from thesvg.org through `POST /api/logo/refresh` with the agent bearer or `CRON_SECRET`; every SVG is sanitized before it is stored or drawn (scripts, foreign objects, event attributes, external references and text removed), and a sanitized file is cached only under an open licence. The index on production was rebuilt on 2026-09-24 (7,422 marks, 4,945 of them brands) and covers 119 of the 146 company names a General Translation seller types (judge-seller's list, `docs/gslides-parity/features/build/logo-coverage-list.txt`); the 27 missing include ServiceNow, Outreach, ZoomInfo, Apollo, PandaDoc, Klaviyo, Microsoft, Deloitte, McKinsey, the localisation competitors Lokalise, Phrase, Smartling, Weglot and Lilt, and General Translation and Locadex themselves. A missing mark is uploaded from its press kit through the dialog's empty state, and the company's own marks are one submission to thesvg.org.
- For agents. `logo.search`, `logo.insert` and `logo.refresh` on the window API, HTTP (`/api/logo/search`, `/api/logo/insert`, `/api/logo/refresh`), MCP and the CLI; a table, a chart or a diagram written by an agent raises the snackbar with Undo in the open editor as before.
- Stays behind Tools > Advanced tools (`docs/gslides-parity/focus/ship-f1afe1e.json`, rendered from the two gate runs of record; the reasons in docs/FEATURES.md section 8 and the README section "Advanced tools"): the templates feature and the notifications inbox (carried from the product round, red in both runs again); Live pointers and Show changes in Version history (carried rows); and the eight P1 controls this ship did not build, whose ids sit in `packages/chrome/src/parked-controls.ts` so the gate reads their rows behind the list (the table's row seam handles, its "+" edges, head bands and bar; the text controls of a group's tail; the outline controls of the word art tail; the picker's Symbol, Wordmark, Color and Mono controls; the brand kit's Find a logo). The roster's Go to slide word is back in the default view: its row read green in both preview runs and on production.
- Known on production, a hotfix named and not a park: after a write of the logo index (a refresh, or a discovery a search makes, at most once a minute per instance) every logo route on a cold instance answers 500 for two to three minutes, because the store's edge refuses the just written file and the index load does not yet treat that as a wait; a tile half or a search on that instance draws nothing for that time. The matrix row `logos.picker.paper-and-ink` read red in both production readings for this reason and is the first item of the round after (the ship note's 13.4). A second row read red in both production readings: `collab.slide-added-appears`, a slide added in a second browser reaching the owner's filmstrip 5 to 10 s later when the two browsers' streams are held by different instances, the second browser bound the sync round measured; it is the second item of the round after, with its seam in the ship note's 13.5.

The evidence: the four audits under `docs/gslides-parity/features/` (objects, fonts, logos, shaders) with the two judges, the verifier's two passes in `docs/gslides-parity/focus/VERIFICATION.md` ("Features round, ship one, pass 1" and "pass 2"), the ship step's note `docs/gslides-parity/features/build/ship.md` (the seam fixes, the previews and their runs, the parked list, the production part) and the production table in VERIFICATION.md ("Features round, ship one, the production table"). ## 2026-09-22, the sync and costs round

The round defines and proves the order of the write path and puts what a page costs while it is open under counted ceilings (docs/SYNC.md). Kevin's words for the round: make syncing and order of stuff much better and cleaner and more optimized for costs; host this on gt cloud vercel to save on costs, and keep turboslide.vercel.app on the personal account at no cost. The round shipped in two deployments in order, because the version record's parsers are strict: `7ea3db9` carries the parser that accepts a record's origin and writes none; `667772f`, one commit after it, writes it; a rollback of the second lands on the first and never earlier. Every sync and cost row passed on the enforce preview built from the tree (`turboslide-eiyqlolll`, the whole run 695 of 714 rows with 4 not driven, the rerun once of the four spec files red by the blob tier's timing 95 of 100 with every sync row green, the last readings 699 passed, 10 failed of which nine the parked list's, 5 not driven) and on production after the release (the core gate of 2026-09-22 read 714 rows, 690 passed, 19 failed of which nine the parked list's and six the assistant's without its key, 5 not driven; the rerun once of the sync and pictures spec files 21 of 24; the sync ordering probe every phase with anomalies 0; the idle deck 3 advanced store calls a minute at most on any instance; docs/gslides-parity/focus/VERIFICATION.md, "Sync and costs round, the production table"; docs/gslides-parity/sync/build/ship.md).

What changed:

- The order of edits. Two people typing into one title slide or one body block at once keep both words, in the same order in both browsers, on the memory tier and on the hosted store; a word typed while offline lands at its shifted place when the tab comes back; a colleague's move of a block and a delete of its slide within the same moment end with the slide gone in both browsers and the loser reading the reducer's sentence. The server transforms every admitted edit past every record between its base and the head before it places it, on every tier, and retries from the original mutations when the head moved while it worked.
- A change is applied once. Every version record names the tab and the ops it carries (from the second deployment on); a write whose answer was lost is resent and answered with the record its first attempt made, never committed again, on the instance that committed it and, since the second deployment, on every instance. The client acknowledges by op id, with the byte match kept for records written before the round.
- A viewer sees the edits live. A person who opens a deck's link as a viewer reads the seller's words within seconds with no reload, with the speaker notes stripped from the stream; a reload in every browser reads the same document at the live revision; Undo takes back your own word and leaves your colleague's.
- What a page costs. An open editor tab makes at most 12 function requests a minute and the deck at most 40 simple and 11 advanced store calls a minute (measured 9.66 function requests, 28 simple and 9 advanced store calls a minute on the preview of record); an editing tab at most 75, 140 and 85 (68.93 function requests, 149 simple where two instances split the edits and 132 with one, 75 advanced); two idle tabs on one deck list nothing and make at most 30 advanced calls a minute (19 advanced a minute, one listing of the assets folder at the second tab's open); a show makes no request and no store call after its load (0 requests and 0 store calls beyond the probe's own reads over three minutes); a viewer or show page opens no agent session unless its address carries `agent=1`, and an editor hidden for ten seconds stops polling and detaches. The pull reads the head object and the records by number and never lists; the snapshot prune runs every 20th commit and at the last stream's close; the card thumbnail renders once when the deck rests; the presence heartbeat slows to 10 s when the tab is quiet; the pulse tick slows to 10 s when a tab is alone. The model of docs/SYNC.md 4.3 and 4.4 (prices read 2026-09-20) puts the month at 50 editor hours a day on Pro at about $22 after this round's items, from $102.58 before it.
- The hosting move, prepared and not run. docs/HOSTING-MOVE.md is the plan to move the deployment to the General Translation team's Vercel account and leave `turboslide.vercel.app` as a static redirect that costs nothing: the redirect files under `hosting/redirect/`, the runbook under `docs/gslides-parity/sync/hosting/RUNBOOK.md` with every command marked Kevin or pipeline, the read only acceptance `scripts/hosting-check.mjs`, the copy fallback `scripts/blob-copy.mjs` and the drain `scripts/probes/presence-drain.mjs`, each tested against the fake store and none run against a real one. Nothing on Vercel was created or changed by the round; production stays on the personal project until Kevin runs the cutover (ship.md section 11).
- For agents. `sync.status` answers the store's view of a deck (`storeCalls` by operation and by the folder each listing read, the answering instance's id) and `deck.info` carries `counts.records` and `counts.holes`; a viewer or show page attaches an agent session only when opened with `?agent=1`.
- Stays behind Tools > Advanced tools, unchanged from the product round (`docs/gslides-parity/focus/ship-7ea3db9.json`): the templates feature, the notifications inbox, Live pointers, Show changes in Version history and the roster's Go to slide word.

The evidence: the three audits under `docs/gslides-parity/sync/` (the ordering, the costs, the hosting), the verifier's two passes in `docs/gslides-parity/focus/VERIFICATION.md` ("Sync and costs round, pass 1" and "pass 2"), the ship step's note `docs/gslides-parity/sync/build/ship.md` (the seam fixes, the run ledger, the two deployments) and the production table in VERIFICATION.md ("Sync and costs round, the production table"). The production run of the core gate on 2026-09-22 read 714 rows: 690 passed, 19 failed (nine of them rows of parked features or controls, six the assistant's against a route production does not run without its key, and four red once on the blob tier's timing and green when rerun: a word of thirty past 5 s, a block's word past 5 s, a drag's reject card, a dropped picture), 5 not driven (the manual clipboard row, the quota row without Upstash, the template deck row behind its parked feature, the resend row whose version list does not yet expose the record's origin, the hidden tab row under Playwright); two rows read red in both production readings, the first word after a colleague joins arriving past 5 s once per fresh pair and File > Open not yet listing a deck made a minute before on another instance. The new write probe read all steps ok and the hosted smoke 40 of 40 on both deployments.

The features the focus round parked come back to the default view where every one of their interactions passed the driven runs: twice on an enforce preview built from the tree and once on production after the release (docs/RETURN.md section 1). What changed:

- Shapes and lines. Insert > Shape places a rectangle, a rounded rectangle or an ellipse with a fill, a border and a label; Insert > Line draws a line or an arrow, and the elbow and curved connectors attach to shapes and follow them.
- Tables. Insert > Table places a table from a grid of columns and rows. Double click a cell to type, Tab to move to the next cell, Tab on the last cell to add a row. Rows and columns are added and deleted from the cell's right click menu and from Format > Table; two cells picked with a Shift click merge and unmerge from the cell menu or the toolbar. Drag a column edge to resize it. The table draws in the show, the PDF and the PowerPoint file.
- Charts, diagrams and word art. Insert > Chart adds a bar, column, line or pie chart whose numbers are edited in the Format options panel; Insert > Diagram lands as one group with editable labels; Insert > Word art places a large outlined text.
- Formatting. Superscript, subscript and capitalization from the Format menu, the right click menu and the keyboard; justified alignment; paragraph spacing; highlight colour; Paint format. Distribute, rotate, flip, group, ungroup and regroup in the Arrange menu. Slide > Change theme switches the deck between the light and dark appearance, and View > Appearance sets the chrome.
- The chrome. The Slideshow button and its options menu are one control with one divider; Enter, Space and ArrowDown work on it and Tab reaches the chevron. Every boundary between the editor's rows is one hairline drawn once. The right cluster keeps one height and one gap; the empty notification slot is gone.
- File and view rows. From template gallery, Open with its list and bundle upload, Import slides from a deck or a bundle, Details, the JPEG, PNG, web page and bundle downloads, Select none, Check slides, Show ruler, the guides, Snap to guides, Show filmstrip, Full screen and the editing modes.

## 2026-09-15, the focus round

The rule this release sets, and every later release keeps: a feature is in the editor's default view only when every one of its interactions works on production and is in the test matrix ([docs/FOCUS.md](FOCUS.md) section 1). The default view is what a seller does weekly: open a deck that exists, duplicate, delete, skip and reorder slides, retype a name and a few numbers, replace a logo or a screenshot, present over a call, and send a PDF or a link.

What changed:

- Tools > Advanced tools. One check row in the Tools menu, off by default and remembered in the browser. Off, the menu bar, the toolbar, the right click menus, Search the menus and the Keyboard shortcuts dialog show the core set and nothing else. On, every parked feature appears in Google's position exactly as before. The parked set, by menu, is FOCUS.md section 3 and the README section "Advanced tools".
- Parked, never deleted. A deck that carries a chart, a table, a diagram, an icon, a material, a code panel, a word art block or a gallery shape still draws it everywhere, and the block can be selected, moved, resized, ordered, aligned, duplicated and deleted through the rows of the default view. The keyboard shortcut of a parked row does nothing while the switch is off. The Font box on the text tail stays visible and disabled with its sentence.
- Shapes. The shape galleries drew every preset as its bounding rectangle, so a seller who picked a callout got a box. Insert > Shape keeps Rectangle, Rounded rectangle and Ellipse, and Insert > Line keeps Line and Arrow, as the minimal set; each is in the default view of a release only when every one of its matrix rows passes, and the rest of the galleries return with the geometry interpreter (FOCUS.md section 4). At the first ship of the round both sit behind Tools > Advanced tools: the verifier's second pass failed 4 of 20 shapes rows and 1 of 5 lines rows on the preview.
- The test matrix. Every interaction of the default view is a row with a stable id in `docs/gslides-parity/focus/core-matrix.json`, driven against the preview and against production at human speed before a release; a row nobody drove is not driven, never passed, and one not driven or failed row keeps its whole feature behind the switch for that release (FOCUS.md section 6). The README section "What works today" is rendered from that file.
- Sharing. A new deck's general access defaults to restricted, the owner alone, and the Share dialog's links grant the viewer, commenter or editor role. Sharing is in the default view only once a stranger and a browser that came by the view link cannot edit on production; until then the PDF is the safe send.
- Fixes to the core set. FOCUS.md section 5 ranks the broken and flaky interactions the production audits of 2026-09-15 found, with the mechanism each audit saw; the release note of the ship lists which passed.
- For agents nothing moves. Every action stays on the CLI, MCP, HTTP and the window API whether or not its menu row is in the default view; `GET /api/agent` lists them all, and the skills document the parked ones as advanced.

The evidence: the seven production audits and their screenshots under `docs/gslides-parity/focus/`, the two judgments beside them, and the build notes under `docs/gslides-parity/focus/build/`.
