the owner's tab: the chip count falls below its earlier reading inside the matrix's 30 s bound,
which is unchanged, and only then closes the context in a `finally`, so no beacon is cut under it
again. Two guards around the navigation: `settled(second)` first, because `EditorRoot.tsx`'s
`beforeunload` handler refuses a navigation while a write is pending, and a `dialog` handler that
accepts the leave warning if one appears anyway (Playwright dismisses a dialog nobody handles, and
a dismissed `beforeunload` dialog keeps the page). The row records an annotation, `presence leave`,
