Decisions this lane took inside the specification, each recorded here so the integrator and the verifier read them once:

1. The kit's stylesheet rides inside every slide (`renderSlide` emits one `<style class="ts-kit-css">` with `themeCss(deck)` and the `@font-face` rules of the faces the deck uses), so every surface that renders slides through the one renderer carries it: the editor stage, the filmstrip clones, the layout tiles (the row `brand.layout.tiles-in-kit` needs nothing more), the show, the print document, the standalone file and the export capture. Empty for a deck without a record that uses the theme's face alone, so every deck stored before the kit renders byte for byte and every existing gate measures the same pixels (the render snapshots changed only where GT blue became `var(--blue, #2f5ce0)`).
2. The footer's logo, the footer text and the counter format belong to the stage's frame band, not to the slide: a slide's layer would animate with the slide in the show. `frameBandOf(deck, theme, resolve)` is the one value; `renderStage` draws it for the render surfaces and the viewer's `Frame` draws it for the editor and the show (R5). Until R5 lands the kit's stylesheet hides the Frame's GT wordmark whenever the kit draws the footer itself (`.wordmark:not(.ts-kit-wordmark)`), so Logo > Remove reads right on every surface and a picture logo shows in the exports and the thumbnails but not yet in the editor's frame.
3. The title slide's logo slot is slide content and stays in `renderSlide`: the GT mark byte for byte for a deck without a record, a picture fitted into the 132 by 84 box, nothing for `none` or a hidden position, and a corner position takes the logo out of the flow into a layer at the sheet's corner (`.ts-kit .ts-kit-logo.pos-*`).
4. GT blue is the kit's Primary (PRODUCT.md 4.1 maps the role to `blue`): `--blue` is a sheet token on both roots, `colorCss('blue')` reads it with the hex as the fallback, `.ic.info` reads it, and a kit's primary redefines it; Accent follows Primary until a kit sets it apart (`--accent`). The tokens parity test pins both.
5. A kit's Background recomputes the hint colour (slide numbers, the wordmark, prompts) when the base titanium reads under 3 to 1 on the new ground, and paints the viewer's slide box (`.pt-slide`) beside `--paper`, because the viewer paints the box over the sheet.

The Font dropdown reads its rows from the renderer's light table (`@turboslide/render/fonts` `fontRows`, the same rows `font.list` answers) rather than fetching `font.list`: the chrome cannot import the fonts package (not linked without an install) and the light table weighs a few kilobytes, so the dropdown opens without a round trip. The colour plate lists the kit's six colours first as their tokens (`ink`, `paper`, `ink-2`, `titanium`, `blue`, `accent`), painted with the kit's hex, so a heading painted Primary follows the kit when the kit changes; the tooltip carries the role's name, the hex and the token id on its second line.
