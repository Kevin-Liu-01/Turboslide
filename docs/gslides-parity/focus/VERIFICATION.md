# Verification passes

The verifiers' passes, ship steps and production tables of every round from the focus round to the realtime round, one file per pass since Round 1 (`docs/NEXT.md` 5.2 item 3). Each file holds the text of its pass unchanged. A citation such as "VERIFICATION C2-F29" or "VERIFICATION.md, Polish round, the production table" names a pass by a heading below. A new pass is a new file in its round's folder under `verification/`, and the run files of a round go into the same folder (`docs/gslides-parity/README.md`, rule 7).
