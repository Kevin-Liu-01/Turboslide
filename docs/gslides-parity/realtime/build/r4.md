### Deviations from the design, with reasons

- `ACCOUNT.signInDialog.socialFailed(reason)` beside `google` (strings.ts): the design's boot line said `signInDialog.failed`, the code path's "That code did not match"; a person refused by Google would read a sentence about a code they never typed. The reason travels in words (`account_not_linked` reads "account not linked"), restricted to `[a-z0-9_]` and 64 characters before it is shown.
- The dialog with no email method and no social provider (a database, `TURBOSLIDE_MAIL=off`, no client): the error row says "No sign in method is configured on this deployment" instead of an empty row, so the state is readable.
- The default host list is the design's five entries and nothing more (`*.vercel.app` considered and left out; request 7 names the consequence for a preview with a database).
