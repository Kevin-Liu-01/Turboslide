### 5. What the integrator should know

- The shared tmp overlay (`os.tmpdir()/turboslide/decks`) is one folder for every tmp store dev server on this machine and it keeps what earlier runs left: it held round five's `sales-pitch`, `book-report` and the other branch folders without a `template.json`, which `listTemplates` skips, and B5a's blank record reached this lane's server only after a copy over the seeded file, because the seed writes missing files alone. A lane that reads template records from a tmp server should clear `templates/` in the overlay first, or start from a fresh overlay.
- `decks/templates/templates.json` is written by `writeTemplateIndex(REPO/decks)` (a two line node script over `packages/store/src/templates.ts`); regenerate it when a template record changes (`template-index.test.ts` fails otherwise, on purpose).
- The gallery's create id is `<slug of the name>-<stamp><4 chars>`, so two decks from one template never collide and the seller's deck is titled after the template.
