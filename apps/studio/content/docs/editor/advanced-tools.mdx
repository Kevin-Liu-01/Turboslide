---
title: Advanced tools
description: The Tools > Advanced tools switch shows more commands in the menus, on the toolbar and in the right click menus.
---

By default, Turboslide shows a core set of commands. These are the commands that a person uses to edit and present a presentation. The **Tools > Advanced tools** switch shows more commands. This browser remembers the setting.

## What the switch does

- **Off** is the default. The menus, the toolbar, the right click menus, Search the menus and the Keyboard shortcuts dialog show the core set.
- **On** shows every other command in its place in the menus. Some of these commands may not work yet.

A hidden command is not removed. A presentation can already contain an object of a hidden command, such as a chart, a diagram or an animated pattern. Turboslide still draws that object on the slide, in the slideshow and in every download. You can still select, move, resize and delete it.

The keyboard shortcut of a hidden command does nothing while the switch is off.

## What the switch shows

The switch shows these commands, among others:

- File: Publish to the web, more download formats and Page setup.
- View: Grid view, Show sections and Edit guides.
- Insert: special characters, icons and the line types other than Line and Arrow.
- Format: Drop shadow, Dither and Edit HTML.
- Tools: Spelling, Notification settings, and an Advanced submenu with Show source and Run an action.

## For agents

Agents do not need the switch. Every action is available on the command line, over MCP, over HTTP and in the page. This is true whether its menu row is shown or hidden. An open editor page reports the setting as `window.turboslide.studio.describe().state.settings.advancedTools`.
