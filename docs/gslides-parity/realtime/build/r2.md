### What the drive found in the code

Three mechanisms the memory tier runs surfaced, each fixed with a unit test before the next run:

1. The remote caret was never measured at its offset. The presence state carries the caret's path as a JSON pointer (`/text`, EditorRoot.tsx's report), `remote-caret.ts` built the run key by plain concatenation (`heading//text`), which matches no `data-run` element and no `boxes.runs` entry, `runElementOf` answered null, and `RemoteCursors` fell to the block's box, which is the run's start. Every reading of the first three runs put the bar at the heading's left edge whatever the offset read (`data-offset` 19, 26, 32, 40), and the production picture of audit-people.md defect 4 ("A drew it at the title's first character") is this. Fixed by `runKeyOf` (the pointer's leading slash stripped) in `remote-caret.ts`, used for the element and the box; the fallback also accepts a block element that is the run itself. Test: `remote-caret.test.ts` "finds the run from a caret whose path is a JSON pointer".
2. A collapsed caret was pushed past a word another person appended at exactly its offset: `shiftRange` moves a point for an insert at `at <= start`, so B's caret after "delta" read at the text's end once A's " charlie" landed at that point (run 1, round 2). A later arrival at the caret's point lands to the right of the owner's text (room.ts admits it on the right), so `shiftPoint` leaves a collapsed caret where it is for an insert at its own offset and keeps `shiftRange` for every other case. Test: the "another person's word appended at exactly B's caret" case in `room-client.test.ts`.
3. Chromium was suspected of giving a collapsed `Range` at the end of a text node no rectangle; the probe (`scratchpad realtime/r2/caret-probe.mjs`) read a rectangle at every offset in every state (a session open, closed, deselected), so the end of the text was never the cause. The neighbour fallback (`caretRect`: the right edge of the character before, else the left edge of the one after) stays as a guard for a run mid render and has its jsdom test.
