### Interfaces V3 exports

- `playStep(target, step, options)` from `live/agents.ts` (6.3):

  ```ts
  export type StepTarget = {
    /** the screen's line containers by width; the hero passes `narrow` alone (44 columns) */
    terminal: Partial<Record<PanelWidth, HTMLElement>>;
    /** the positioned wrapper of the slide the step changes: the ring and the flag are drawn in it */
    sheet: HTMLElement;
  };
  export type StepOptions = {
    customer: string;
    /** the CLI's revision the answer prints (the page deck's), default the recorded one */
    revision?: number;
    /** clears the screen before the command (the hero's Restore) */
    clear?: boolean;
    /** called when the answer has printed and the beat has passed: the caller sets the slide's new state and returns the changed element (null: no ring, as Restore) */
    land(): Element | null;
    band: SequenceBand;
    track: boolean;
  };
  export type StepHandle = { pause(): void; resume(): void; finish(): void; readonly done: Promise<void> };
  export function playStep(target: StepTarget, step: LoopStep | ChipStep, options: StepOptions): StepHandle;
  ```

  `LoopStep` is `HOME_RUN.loop[i]` (Restore and the three steps, each with its command, typed length, answer, landing and schedule); `ChipStep` is a chip's recorded command for the deck state the page holds. The ring and the flag are ink.
- `openShow(container, slideId)` from `live/show.ts`: opens the show inside `container` on that slide, focus on its stage, and returns `{ close(): void }`; Escape and Exit close it and return focus to the element that had it.
