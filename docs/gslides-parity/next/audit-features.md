## 3. Where Turboslide already does more than Google Slides

1. Agents edit through the same actions a person uses. 193 actions, 169 MCP tools and 177 HTTP paths (`packages/theme/brand/facts.json` 5, 9, 13, written 2026-09-29), each write carrying an author of kind `human` or `agent` (`packages/schema/src/mutations.ts` 186). Google's own page says embedded charts and videos in PowerPoint files are converted to images (support answer 6055139, 2026-10-01), and research 07 line 214 records layouts shifting in the round trip.

4. Tailor for a customer in one undo step. Tools > Tailor for a customer is in the default view (drive `menu-tools`), and it is the Assist panel's first card (drive `assist-panel`); `deck.tailor` is on every transport (`actions.ts` 294). Google's route is Find and replace (research 07 line 44).
5. An assistant with no plan gate. The router model answered twelve assist prompts for $0.00117 in total, about $0.0001 per call (`assist-router.md` 18, 2026-09-29). 6. A logo picker with licence words. Insert > Logo over the thesvg.org index, sanitized and stored as twins (`apps/studio/src/server/logos.ts` 1 to 15; drive `menu-insert`). Research 07 line 225 records Google's web image search showing no attribution.

12. The running cost. The General Translation team's share for Turboslide is $3 to $5 a month (`docs/REALTIME.md` 19, read from the bills on 2026-10-01). The repository is MIT licensed (`facts.json`, `licence`).
