---
title: Text, pictures and shapes
description: Write and format text, add and replace pictures and logos, draw shapes and lines, edit tables and charts, and place animated patterns.
---

Everything on a slide is an object: a text box, a picture, a shape, a line, a table, a chart or an animated pattern. Click an object to select it, then use the toolbar, the Format menu or Format options to change it.

## Text

Click a text box and type. A placeholder that reads Click to add title or Click to add text becomes a text box when you type in it.

- **Insert > Text box** places a new box: click the slide, or drag to draw one.
- Bold, Italic and Underline are Cmd+B, Cmd+I and Cmd+U (Ctrl on Windows). Format > Text holds the rest: strikethrough, superscript, subscript, the font, the size and the capitalization.
- Format > Align & indent sets the alignment and the indent. Format > Line & paragraph spacing sets the spacing.
- Format > Bullets & numbering starts a list: Cmd+Shift+8 for bullets and Cmd+Shift+7 for numbers (Ctrl+Shift on Windows).
- Format > Clear formatting (Cmd+\\) removes the size, weight, color and border changes from the selection.
- **Insert > Link** (Cmd+K) links the selected text to an address or to another slide.

Edit > Find and replace (Cmd+Shift+H) changes a word on every slide at once.

## Pictures and logos

| To                                    | Do this                                                                                                                |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Add a picture                         | Insert > Image > Upload from computer, or drop the file on the slide. Pictures can be up to 25 MB, or 50 MB signed in. |
| Add a picture from the web            | Insert > Image > By URL, then paste the address.                                                                       |
| Add a company logo                    | Insert > Image > Logo, type the company's name and pick the logo.                                                      |
| Replace a picture                     | Drop a file on it, or right click it and choose Replace image. The new picture keeps the size and the place.           |
| Crop                                  | Format > Image > Crop image, drag the handles, press Enter.                                                            |
| Put a picture in a shape              | Format > Image > Mask image.                                                                                           |
| Describe a picture for screen readers | Format > Alt text (Cmd+Option+Y).                                                                                      |

**Use on every slide** in Format > Image makes the selected picture the logo on the title slide and in the footer of every slide.

Pictures can be PNG, JPEG, WebP or GIF; an animated GIF keeps its first frame, and HEIF and JXL are refused. On turboslide.com and any hosted studio, SVG is refused too, and every picture is saved again as a new file, so nothing else from the original file is kept.

## Shapes and lines

**Insert > Shape** holds rectangles, rounded rectangles and ellipses, and galleries of shapes, arrows, callouts and equation signs. Click a shape's tile, then click the slide to place it or drag to draw it at a size.

**Insert > Line** draws a line, an arrow, an elbow connector or a curved connector. A connector whose ends sit on two shapes follows them when they move.

Format > Borders & lines sets the color, the weight, the dash and the ends of a line or a border.

## Tables and charts

- **Insert > Table** shows a grid: point at the size you want, up to 20 columns by 20 rows, and click. Click a cell and type; Tab moves to the next cell. Format > Table inserts and deletes rows and columns, merges cells and turns on a header row.
- **Insert > Chart** adds a bar, column, line or pie chart with sample numbers. Open Format options to edit the numbers and the labels.
- **Insert > Diagram** adds a grid, a hierarchy, a timeline, a process, a relationship or a cycle diagram.

## Animated patterns

**Insert > Animated pattern** opens a gallery of 38 patterns in five groups. Each still shows a pattern in one of its presets; click one to place the pattern with that preset. On the slide a pattern takes your theme's colors.

| Group    | Patterns                                                                                                                                            |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Fluid    | Gem smoke, Smoke ring, Swirl, Metaballs, Warp, Water                                                                                                |
| Light    | God rays, Neuro noise, Pulsing border, Caustics, Nebula, Spectral bloom, Radiant void, Galactic rings, Holo cloth                                   |
| Metal    | Liquid metal, Liquid glass, Iridescent foil, Architectural chrome, Chrome glares                                                                    |
| Gradient | Mesh gradient, Grain gradient, Static radial gradient, Static mesh gradient, Color panels, Dot orbit, Silk ribbons, Relief gradient, Orbit gradient |
| Graphic  | Dithering, Voronoi, Soft register, Dither gradient, Glyph field, Spiral, Dot grid                                                                   |

Two engines draw the patterns, Paper Shaders and Glyphfield, so Gradient holds two cards named Mesh gradient and two named Grain gradient, one of each from each engine: 11 cards in all. Type Glyphfield or Paper in the search field to see one engine's patterns.

Select a pattern and open Format options to change its preset, its colors, its form, its light, its orientation and its speed.

Every moving pattern has a still: the moment that downloads, thumbnails and any place where it does not play show. Under **Still** in Format options, Play runs the pattern and Pause keeps the moment it shows as the still. The slider and the time field choose a moment from 0 to 60 seconds. Static radial gradient, Static mesh gradient and Dot grid do not move and have no Still group.

**Slide > Playback** sets whether patterns move in the slideshow and the viewer: Play in the show, or Hold the still. Apply sets it for the whole presentation, and Apply to selected for the selected slides. A viewer with Reduce motion on, or with Play animated patterns set to Off, sees the still.

**Tools > Preferences > Play animated patterns** is a setting of this browser: On moves the selected pattern while you edit and the patterns in the slideshow and the viewer, In the show only (the default) moves them in the slideshow and the viewer alone, and Off shows the still everywhere. A change takes effect at once.

## Animations

Select an object and choose **Insert > Animation**, or Animation in the object's right click menu, to open the Animate panel. Add animation picks a role and an effect. An entrance or an exit takes Fade, Rise in, Slide in, Pop in, Wipe or Draw, and on an object with text also Type on, Word rise, Line reveal, Letter stagger or Tracking in; an exit plays its effect backwards. An emphasis takes Push in, Float or Pulse. Each effect then has:

- **Effect**: how the object moves.
- **Start**: On click waits for the next click or key in the slideshow, With previous starts with the effect before it, and After previous starts when the effect before it ends.
- **Delay** and **Duration**, in seconds from 0 to 60.
- **Remove**, which takes the effect off the object.

The panel heads each effect with the step it plays in: When the slide opens, Click 1, Click 2 and so on. In the slideshow each click or key plays the slide's next step, and the show moves to the next slide once the steps are done. An agent writes the same effects with the `motion.*` actions.

## Arrange objects

The Arrange menu orders, aligns, distributes, rotates and groups the selected objects.

- **Order**: Bring to front, Bring forward, Send backward, Send to back.
- **Align**: one object lines up with the slide; several objects line up with each other.
- **Group** (Cmd+Option+G) moves, resizes and formats several objects as one. Ungroup separates them again.

Arrow keys nudge the selection; Shift and an arrow nudge it further.
