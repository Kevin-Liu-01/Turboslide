**R2, B1, `packages/viewer/src/Editor.tsx`: the ring follows the rows at every input (item 2,
row `tables.rows.ring-follows-typing`).** In the table branch of `growAfterBurst` (2031 to 2052)
the wrapper's height is set from `readTableRows` only when a burst commits. Add the same measure
to the session's `onInput` (7287, `onInput={measure}`): when `editingRef.current` names a table
cell, read `readTableRows(blockEl, k, window)`, take `tableRowsHeight(measure)` (table-fit.ts),
and when it exceeds the wrapper's current height set `wrapper.style.height` to it and call
`measure()` so the overlay's ring follows; the `pos.h` write stays with the burst as it is. A
sketch:

```ts
const followTableRows = () => {
  const current = editingRef.current;
  const el = body.current;
  const slideNow = slideRef.current;
  if (!current || !el || !slideNow) return;
  const block = blockById(slideNow, current.blockId);
  if (block?.type !== 'table') return;
  const blockEl = el.querySelector<HTMLElement>(`[data-block="${block.id}"]`);
  const wrapper = blockEl?.parentElement?.closest<HTMLElement>(`.free[data-free="${block.id}"]`);
  const stage = el.parentElement;
  const k = stage ? stage.getBoundingClientRect().width / SHEET.width : 0;
  if (!blockEl || !wrapper || !(k > 0)) return;
  const rows = readTableRows(blockEl, k, window);
  if (rows === null) return;
  const height = Math.ceil(tableRowsHeight(rows));
  if (height > (parseFloat(wrapper.style.height) || block.pos?.h || 0) + 1)
    wrapper.style.height = `${height}px`;
};
// onInput={() => { followTableRows(); measure(); }}
```
