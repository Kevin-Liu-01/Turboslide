The editor opens at `/edit/<id>` for a presentation that you own or can edit. It opens at `/new` for a new presentation. The editor has four areas. The title row and the menus are at the top, and the toolbar is under them. The filmstrip is on the left, and the slide is in the middle. The speaker notes are under the slide.

## The title row

The title row shows the name of the presentation. Click the name to rename the presentation. The right end of the row shows the people who have the presentation open, Share and Slideshow.

- **Share** opens the sharing dialog. The dialog holds the view and edit links and the people that you invited by name.
- **Slideshow** presents from the current slide. The arrow beside it holds Presenter view and Start from beginning.

## The menus

Every command is a row in one of nine menus. Help > Search the menus (Alt+/) finds a row by its name.

| Menu    | What it holds                                                                                                                                                                           |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| File    | New presentation, Open, Import slides, Make a copy, Share, Download, Rename, Move to trash, Version history, Details and Print.                                                         |
| Edit    | Undo, Redo, Cut, Copy, Paste, Paste without formatting, Delete, Duplicate, Select all, Select none and Find and replace.                                                                |
| View    | Slideshow, Zoom, the ruler, guides, snapping, comments, live pointers, speaker notes, the filmstrip, the editing mode and Full screen.                                                  |
| Insert  | Images and logos, a text box, shapes, a table, a chart, a diagram, word art, lines and connectors, an animation, a link, a comment, a new slide, slide numbers and an animated pattern. |
| Format  | Text, alignment and indents, line spacing, lists, tables, images, borders and lines, Format options, Clear formatting and Alt text.                                                     |
| Slide   | New slide, Duplicate slide, Delete slide, Skip slide, Move slide, Change background, Apply layout, Playback, Transition and Change theme.                                               |
| Arrange | Order, Align, Distribute, Center on page, Rotate, Group, Ungroup and Regroup.                                                                                                           |
| Tools   | Preferences, Tailor for a customer, Check slides and Advanced tools.                                                                                                                    |
| Help    | Search the menus, Help, Help Turboslide improve and Keyboard shortcuts.                                                                                                                 |

A row that cannot run on the current selection is grey. Its tooltip gives the reason.

## The toolbar

The toolbar starts with the same controls for every selection. These are Search the menus, New slide with its layout arrow, Undo, Redo, Print, Paint format and the zoom box. After a divider, the toolbar shows the controls for the selection. A text box gets text controls, a picture gets crop and replace, and a shape gets fill and border. Point at a control to see its name and its key.

## The filmstrip

The filmstrip on the left shows every slide as a card, in order.

- Click a card to show that slide. Shift click selects a range. Cmd click (Ctrl click on Windows) adds one card.
- Drag a card to move the slide. Cmd+Up and Cmd+Down (Ctrl+Up and Ctrl+Down on Windows) move the selected slides one place.
- Right click a card to see New slide, Duplicate slide, Delete slide, Skip slide and the layouts.
- A skipped slide stays in the filmstrip as a shaded card. The slideshow and the downloads leave it out.

View > Show filmstrip hides and shows the filmstrip.

## The slide

Click an object on the slide to select it. Drag the object to move it, and drag a handle to resize it. Type to replace the text of a selected text box. Shift click adds an object to the selection. A drag on an empty part of the slide selects every object that the drag touches.

- The arrow keys move the selection one pixel at a time. Shift and an arrow key move it by a larger step.
- Cmd+D duplicates the selection, Delete removes it, and Cmd+Z undoes the last change.
- Right click an object to see Cut, Copy, Paste, Order, Align and the commands for that kind of object.
- Format > Format options opens a panel with the size, position and every setting of the selection.

The zoom box on the toolbar and View > Zoom set the zoom from 25% to 1600%. View > Zoom > Fit shows the whole slide.

## Speaker notes

The notes pane under the slide holds what you will say for that slide. Click the line that reads Click to add speaker notes, then type. Drag the line above the pane to make the pane taller. The notes show in Presenter view. You can include them in a PDF or PowerPoint download. View > Show speaker notes hides and shows the pane.

## Find and replace

Edit > Find and replace (Cmd+Shift+H, or Ctrl+H on Windows) finds text on every slide and in the speaker notes. Type the text to find and the replacement text. Next and Prev step through the matches. Replace changes the current match. Replace all changes every match in one step, and Undo reverses that step.

## Assist

Click **Assist** in the title row (Cmd+J) to open the assistant beside the slide. When a slide is selected, the assistant offers three commands. Make it shorter and Write speaker notes send a request to the assistant. Tailor for a customer opens a dialog and sends no request. You can also type a request about the slide.

The assistant replies with a card. The card shows the text before and after the change, with the changed words marked. Nothing changes until you click Accept. The change is one step, and Undo reverses it. Dismiss removes the card. The assistant changes only the text and the speaker notes of the slide in the request.

Commenters and editors can use the assistant. Without an account, a person can send 20 requests a day, unless the studio sets another number. A signed in person can send 300 requests a day. If the admin of a studio turns the assistant off, the studio shows "The assistant is off on this Turboslide".

## Version history

Turboslide saves every change as you make it, so there is no Save button. File > Version history > See version history (Cmd+Option+Shift+H) lists the saved versions. Each version shows the time and the person who made the change. Click a version to see the presentation as it was. Click Restore this version to bring that version back. File > Version history > Name current version gives the current version a name, so you can find it later.

Editors and the owner can open version history. An editor who may not share sees stand-ins in place of the names of other authors. See [What other people see](/docs/sharing#what-other-people-see).

## Saving offline and limits

When the editor cannot reach the studio, your changes wait in this browser. The editor sends them when it reconnects. The editor shows the count of waiting changes, for example "3 unsaved changes from this browser". Up to 1 MB of changes can wait. Past that limit, the editor shows "Unsaved changes are full. Reconnect to save them." Changes that waited more than 24 hours come back as "Unsaved changes from Oct 7", with Copy Text and Discard. Copy Text lets you keep their text without writing over newer work.

A slide holds at most 200 kB. A change that would pass this limit is refused with the message "This slide would pass 200 kB. Split the text into another slide."

## Modes

View > Mode switches between three modes:

- **Editing** shows the handles, the notes pane and Format options.
- **Commenting** lets you add and answer comments without moving anything.
- **Viewing** is read only.

A person with view access or comment access gets the matching mode.
