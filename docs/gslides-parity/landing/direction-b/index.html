Slideshow starts on the current slide. Presenter view opens in a second window with the timer, the notes and the next slide. A skipped slide stays out of the show.

Export to PDF and PowerPoint

File > Download writes a PDF or a PowerPoint file. The PowerPoint file matches the screen pixel for pixel.

In the browserIn the PowerPoint file

Drag the handle to compare the two. Hold the pointer on the slide to see both at ten times their size.

Animated patterns in the theme's colors

Insert > Animated pattern adds one of 17 patterns to a slide. It moves in the editor and in the show. Every export carries its still frame.

The still frame is the picture the PDF and the PowerPoint file carry.
