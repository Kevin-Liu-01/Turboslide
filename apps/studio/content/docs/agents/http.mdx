---
title: HTTP actions
description: Call any action with one POST request, read its contract, and render slides and export files over HTTP.
---

Every action has an HTTP endpoint: `POST /api/actions/<id>`. The body is the action's input as one JSON object.

```sh
curl -X POST "https://www.turboslide.com/api/actions/slide.list?deck=<id>" \
  -H "authorization: Bearer <token>" \
  -H "content-type: application/json" \
  -d '{}'
```

## The request

| Part         | What to send                                                                                                                                                                       |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Presentation | `?deck=<id>` names the presentation. A write that changes a presentation and names none is refused with 400 and `code: "deck_required"`; a read without it reads the example deck. |
| Token        | `Authorization: Bearer <key>` on a hosted studio, with an API key from `turboslide login`. On localhost the routes answer without one.                                             |
| Author       | Every write is recorded under the key's owner as `agent:<tokenId>`. The `x-turboslide-author` header and `?author=` only label the run; they never change the author.              |
| Force        | `?force=1` writes to a slide another author has leased. Without it, that write is refused with 409 and the holder.                                                                 |
| Size         | At most 1 MB per request body.                                                                                                                                                     |

A key's scopes limit what it may do: `read`, `comment`, `write`, `export`, `share` and `admin`. A key without the `share` scope reads other people's ids as stand-ins (`ref_` and 22 characters). The [account reference](/docs/reference/account) lists the key actions.

A picture can be up to 25 MB without an account and 50 MB signed in. A hosted studio refuses SVG, re-encodes every picture, and flattens an animated GIF to its first frame; HEIF and JXL are refused everywhere.

`GET /api/actions/<id>` returns the action's contract: the input and output JSON Schema, the transports and whether this studio runs it. `/openapi.json` is the OpenAPI 3.1 document of every endpoint, and `/api/agent` describes the studio.

## Errors

An action's error answers with `{ "error": { "name", "status", "message", "code", "pointer", "currentRevision", "current", "holder", "capability" } }`; only the fields that apply are present.

| Status | Means                                                                                                                       |
| ------ | --------------------------------------------------------------------------------------------------------------------------- |
| 400    | The input is wrong. `code` and `pointer` name the field.                                                                    |
| 401    | No key, or a key this studio does not accept. A key from `turboslide login` past its 90 days answers `code: "key_expired"`. |
| 403    | The key may read the presentation but not do this. `capability` names what is missing.                                      |
| 404    | No such presentation, slide or object, or a presentation the key may not read. The two answer the same.                     |
| 409    | The presentation changed since `baseRevision`, or another author holds the slide. The answer carries the current document.  |
| 410    | A revoked publish link, or a download address that expired.                                                                 |
| 429    | A quota is used up. The body is `{ "error": "rate_limited", "message", "quota" }` and `Retry-After` says when to try again. |
| 501    | This studio does not run the action.                                                                                        |
| 503    | The admin turned the feature off. The body is `{ "error": "unavailable", "message" }` with `Retry-After: 60`.               |

## Send a write again

A write that may have landed before a timeout can be sent again with `Idempotency-Key`: one value per write, such as a UUID, and the same key with the same body on the resend. A resend of a write that landed is not applied again; it answers 200 with that write's answer and the header `idempotent-replayed: true`.

| Answer                          | Means                                                         |
| ------------------------------- | ------------------------------------------------------------- |
| 400 `invalid_idempotency_key`   | The key is not 1 to 255 visible ASCII characters.             |
| 400 `idempotency_not_supported` | The action does not take a key.                               |
| 422 `idempotency_key_reused`    | The key was already sent with another action or another body. |

The writes to slides, objects, text, sections, pictures and the presentation's settings take the key, as do `version.restore`, `fix.run` and `assist.accept`; the OpenAPI document names the header on each of them. Making, copying, trashing or sharing a presentation, a template, a named version, a comment, a lease, presence, and the account and admin actions do not.

## Renders and downloads

- `GET /api/render/<slideId>?deck=<id>&theme=light&scale=1` answers the slide as a PNG. `?format=json` answers the render record instead. A full size render needs the bearer.
- `GET /api/render/<slideId>?deck=<id>&w=320` answers a thumbnail 160, 320 or 640 pixels wide to anyone who can open the presentation.
- `POST /api/export/<id>?sync=1` with the `export.run` input answers the file. Send `?sync=1` every time: a hosted studio always works that way.
- A file over 4.5 MB cannot be returned directly. On a studio with a Blob store the answer is 302 to `/api/download/s.<token>`, an address signed for the caller that works for ten minutes and answers 410 after; without a Blob store it is 413, so export one theme or fewer slides.
