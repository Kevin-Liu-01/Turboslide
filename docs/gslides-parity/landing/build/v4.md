### Interfaces V4 exports (in `V4#9` unless named)

From `live/motion.ts` (the first pass's `ms`, `ease`, `smoothstep`, `reduced`, `slowFactor`, `play`, `sequence`, `finishBand`, `finishAll`, `runningCount`, `onceInView`, `hintInView`, `installGuards` stand; `onceInView(el, arm, play, end?)` gains the optional `end`, the end state at once when Pause Motion is pressed as the band arrives):

```ts
export type LoopSpec = {
  kind: 'demonstration' | 'field';
  play(): void;   // start or resume from the held frame; called by the scheduler alone
  pause(): void;  // hold the frame: no frame callback and no timer once it returns
  still(): void;  // draw the still (reduced motion, Pause Motion at load, a change to reduced motion)
  id?: string;    // L-H for band 'hero', P-L for 'people', P-T for 'patterns' by default
};
export function loop(band: string, element: Element, spec: LoopSpec): { readonly id: string; stop(): void };
export function motionPaused(): boolean;                         // html[data-motion="paused"]
export function onMotionChange(fn: (paused: boolean) => void): () => void;
export function onFrame(tick: (dt: number, now: number) => void): () => void; // the one frame clock; dt / slowFactor()
export function timeline(length: number, reset: () => void): Timeline;         // B's Seq: at(t, fn(instant)), advance(dt), seek(t)
// window.tsHomeMotion = { paused, running(): string[], registered(): string[] } once the core starts
```

The scheduler plays at most one demonstration (the one most in view of those at least half in view; the one playing keeps a tie) and the two fields most in view with any part in view; it pauses every loop on a hidden tab and under Pause Motion and resumes the loops in view after them; a change to reduced motion pauses every loop and calls its `still`. A press of Pause Motion also lands every running one shot and visitor sequence (`finishAll`) and takes H5's `ts-intro` away.

For V1's L-H (`live/stage.ts`, `V1#15`): register the stage with `loop('hero', stage, { kind: 'demonstration', play, pause, still })` (its id is `L-H`); `play` waits for `heroDeveloped()` (`live/hero.ts`, which resolves when H5 has ended, at once when it never ran) and one beat (`ms('beat')` is 0 under reduced motion, so use the 500 ms of 3.4 as a constant) before the cycle's first step, and `pause` must cancel that wait; drive the cycle with `onFrame` and `timeline` so a paused loop holds no timer, or keep V3's `playStep` handle's `pause()` and `resume()`; call the handle's `stop()` on a press, a key or a change to slide 5 (2.2), which leaves the frame at rest.
