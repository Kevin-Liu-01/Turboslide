title: Download and export
description: Download a presentation as PowerPoint, PDF, pictures, a web page or a Turboslide file, with or without speaker notes and skipped slides.
---

Choose **File > Download** and pick a format. Every download comes from the same renderer as the editor, so the file shows what you see on the slide.

## Formats

| Format                       | What you get                                                                                                                                                                                |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Microsoft PowerPoint (.pptx) | A PowerPoint file. Pictures, the default, draws each slide as a picture, so the file looks exactly like Turboslide. Editable text keeps the text as text that you can change in PowerPoint. |
| PDF Document (.pdf)          | One slide per page.                                                                                                                                                                         |
| JPEG image (.jpg)            | The current slide as a picture.                                                                                                                                                             |
| PNG image (.png)             | The current slide as a picture.                                                                                                                                                             |
| Web page (.html)             | One file that opens in any browser and presents the slides.                                                                                                                                 |
| Turboslide file (.zip)       | The whole presentation with its pictures, which File > Open and Import slides read back.                                                                                                    |

The web page and the Turboslide file are under **File > Download > More formats**.

## Options

**File > Download > More formats > Download options** opens the download dialog. The dialog shows the file type and these options:

- **Include speaker notes** adds the notes to a PDF or a PowerPoint file.
- **Include skipped slides** keeps the slides that you skipped.

## Who can download

Editors and the owner can always download. Viewers and commenters can download, print and copy only while the sharing setting **Viewers and commenters can download, print and copy** is on. Include speaker notes needs edit access. Include skipped slides needs comment access or more.

A studio limits downloads per person: 5 a day without an account and 30 a day when signed in. Each person can run one download at a time. Past the limit, the studio refuses the download with the message "You have reached today's export limit".

## PowerPoint: Pictures or Editable text

<Tabs>
  <Tab title="Pictures">
    Each slide is a picture of the slide as Turboslide draws it, so the file looks the same on every
    computer. The file keeps the words as hidden text. You can search and select the words, but you
    cannot edit them.
  </Tab>
  <Tab title="Editable text">
    The text stays editable, so you can change it in PowerPoint. Each text box keeps its place and
    its line breaks. Icons, diagrams and pictures go into the file as pictures. PowerPoint draws the
    text, so the letters can look slightly different from the letters in Turboslide.
  </Tab>
</Tabs>

## Long presentations

On turboslide.com, a presentation with more than 60 slides is exported in batches of 60. The download dialog shows the progress. The file downloads when the last batch is done. If a batch fails, Turboslide retries that batch alone.

## Print

**File > Print** (Cmd+P) opens the print preview with one slide per page. **File > Print settings and preview** shows the options first.
