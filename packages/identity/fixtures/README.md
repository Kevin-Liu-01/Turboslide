# Identity fixtures

Data files `@turboslide/identity` reads at import time. Each is derived from a published source
on the date named inside the file; `scripts/` has no generator yet, the derivation is recorded in
`docs/gslides-parity/build-3/b3.md` (stage 1) and is three regular expressions over the source
text.

| File                     | Source                                                                                                                   | Licence                                                                                                                                                                    | What it holds                                                                                                                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `confusables.json`       | `https://www.unicode.org/Public/security/latest/confusables.txt`, Unicode 17.0.0, dated 2025-07-22, read 2026-09-13      | Unicode License v3 (`LICENSE-UNICODE.txt`)                                                                                                                                 | Every single code point source of the `MA` table mapped to its prototype string, keyed by the source code point in lower case hexadecimal. The whole table has single code point sources, so nothing is dropped. |
| `identifier-status.json` | `https://www.unicode.org/Public/security/latest/IdentifierStatus.txt`, Unicode 17.0.0, dated 2025-08-01, read 2026-09-13 | Unicode License v3                                                                                                                                                         | The `Allowed` ranges of `Identifier_Status` as inclusive `[first, last]` pairs; every other code point is `Restricted`.                                                                                          |
| `nd-zeros.json`          | computed from the JavaScript engine's own Unicode tables (`\p{Nd}` over every code point, split into runs of ten)        | none needed                                                                                                                                                                | The code point of the zero digit of every decimal digit system, for the mixed number check of UTS #39 section 5.3.                                                                                               |
| `ldnoobw-en.json`        | `https://github.com/LDNOOBW/List-of-Dirty-Naughty-Obscene-and-Otherwise-Bad-Words`, file `en`, read 2026-09-13           | Creative Commons Attribution 4.0 International (the repository's `LICENSE`); attribution: "List of Dirty, Naughty, Obscene, and Otherwise Bad Words" by Shutterstock, Inc. | The English list, one entry per line as published. Other languages are added as `ldnoobw-<lang>.json` when a request's languages need them.                                                                      |

Nothing here is Google's: the label words are Turboslide's own material and element nouns
(`src/labels.ts`), not an animal list.
