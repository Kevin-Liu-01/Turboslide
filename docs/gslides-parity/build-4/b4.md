### 1.4 The thumbnail cache and the render route (0.31, 3.2; item 3)

`apps/studio/src/server/thumbs.ts` (rewritten), `routes/api/render.$slideId.ts`, `warm.ts` (unchanged), `root.ts`:

- The disk cache is keyed by stamp, `<state>/thumbs/<deckId>/<stamp>/<theme>@<width>/<slideId>.png`; the store cache is `decks/<deckId>/.thumbs/<stamp>/...` with `cacheControlMaxAge` of a year, through `exportBlobClient()` on the `blob` tier and nothing on `file` and `tmp`. `slideStamp` is the server's copy of the editor's arithmetic (asserted equal in `thumbs.test.ts`).
- `getThumbnail(request, { blob, access })`: the disk, then the store under the asked stamp (`r`, else the slide's current stamp), then, for a request without `r`, the newest stored stamp of the slide answered at once with the current one rendered behind the response (`afterResponse`, `@vercel/functions` `waitUntil` when a request context exists, a detached promise on a checkout), then the render (the worker's screenshot downsized, written to disk, put to the store, the retention prune behind the response). A stored answer on a public store is a 302 to the Blob URL (`kind: 'stored'`); on a private store (`TURBOSLIDE_BLOB_ACCESS=private`, or the layout v2 documents token, whose split client routes `.thumbs/` with the documents) the body is streamed. Headers: `public, max-age=31536000, immutable` with `r`, `public, s-maxage=60, stale-while-revalidate=86400` without; `x-turboslide-stamp`, `-fresh`, `-source`, `-cached`, `-revision`, `-thumb`, the etag by stamp. The signed URL of SPEC-3 8.13 (`s`, the grant) is verified before any of this as before.
- The route reads `r` through `isThumbStamp` (eight hex digits, a revision, or a short opaque name) and passes it; `revisionInUrl` is `r !== null`.
- `warmThumbs` writes each slide under its current stamp on disk and in the store (one render job, Chromium launched once) and skips the slides the store already holds.
- The sweep of `root.ts` (`revisionEntries`): a numbered thumbs folder is dead below the newest number as before; a stamp folder is never dead by age (the current stamp is not knowable from the folder's name) and the byte budget evicts it oldest first. `root.test.ts` gains the row.
- `thumbs.test.ts` (new): the header set per URL shape, the 302 and the body, the stamp grammar, the store access rule, the stamp arithmetic, the pathname round trip and the retention (the fourth stamp evicts the first at every width; the light theme is another set).
