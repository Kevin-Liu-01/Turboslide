## Transports

- `cli`: `turboslide <command> --json`, machine output on stdout, human output on stderr; exit 0, 1 (findings at the gate or a verify failure), 2 (usage or validation error). `--author agent:<runId>` and `--base-revision <n>` on every write.
- `mcp`: tools named `deck_<action>` over stdio (`turboslide mcp`) or streamable HTTP at `/mcp`; render tools return image content beside the JSON.
- `http`: `POST /api/actions/<id>` with the input as JSON; `GET /api/agent` for the manifest, `/openapi.json` for the contract.
- `window`: `window.turboslide.studio.invoke(<id>, input)` in the studio; see `turboslide-studio`.

## Write protocol

1. Read: `deck.info`, then `slide.get` for the slide you will touch.
2. Make the smallest change: one `block.set`, `text.replace` or `slide.update` with a mutation list; `slide.replace` only when the whole slide changes.
3. Write with the `baseRevision` you read and `--author agent:<runId>`; on 409 re-read the returned document and retry once.
4. Take `slide.lease` before a series of writes to one slide; release by letting it expire.
5. Re-read from the response, not from memory; then render both themes and lint (`turboslide-verify`).

## Errors

| Class                 | HTTP | When                                                                                    |
| --------------------- | ---- | --------------------------------------------------------------------------------------- |
| `TypeError`           | 400  | malformed input, with the Zod path                                                      |
| `RangeError`          | 404  | an unknown action, label or id                                                          |
| `ConflictError`       | 409  | a stale baseRevision or a held lease, with the holder and the current document attached |
| `NotImplementedError` | 501  | an action declared in the table whose implementation lands in a later milestone         |
| `Error`               | 500  | renderer and codec failures                                                             |
